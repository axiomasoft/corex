# Реестр внешних референсов

Строка реестра называет **конкретный заимствуемый механизм**, а не проект целиком. «Учимся у
Symfony» — не запись; «заморозка контейнера до обслуживания запросов» — запись.

| Проект | Заимствуемый механизм | Где применён |
|:--|:--|:--|
| Symfony | Валидация и компиляция вкладов до заморозки; `@internal` вне BC-промиса; ограниченный срок `@experimental` | EXT-004, API-002, API-005 |
| Drupal | Категория пакета в `type`, конфигурация инструментов в `extra`; кеш определений плагинов | `taxonomy.md`, EXT-003 |
| TYPO3 | Версионированное поддерево метаданных расширения в `composer.json` | `taxonomy.md` (`schema-version`) |
| Laravel | Обнаружение пакета через `extra.laravel`; локальная политика — в корне проекта | `taxonomy.md` |
| Composer | `extra` как открытая точка расширения с владеемым неймспейсом; стабильность — в версии | `taxonomy.md`, D11 |
| Shopware | Жизненный цикл расширения install/activate/deactivate/uninstall | EXT-003 |
| Shopify | Эксклюзивное владение данными компонента; связь через границу — нарушение; машинная проверка вместо соглашения | DATA-001, DATA-003 |
| Spring Modulith | Модульная граница кода не делает базу приватной сама по себе | §7 `data-ownership-policy.md` |
| [CloudEvents 1.0.2](https://github.com/cloudevents/spec/tree/v1.0.2/cloudevents) | Structured JSON; `type` как стабильное публичное имя; внутренний/внешний профили в message-policy.md | MSG-003, MSG-004 |
| Standard Webhooks | Идентификатор доставки, подпись, защита от повтора, мультиподпись при ротации | P14 |
| Stripe | Семантика ключа идемпотентности и конфликт при том же ключе с другими параметрами | P13 |
| Atlassian | Additive-first; клиент запрашивает capability, а не выводит её из версии | API-006, D2 |
| GitLab | Долгоживущий мажор в пути для self-hosted | D2 |
| Grafana | Группы API со статусами зрелости | D2 |
| Google AIP / Microsoft Graph | Единый контракт длительной операции: отправка, опрос, результат, отмена, срок жизни | D9, P14 |
| Salesforce | Разделение scope приложения и прав пользователя на запись и поле | P13 |
| PostgreSQL | Индекс не отдаёт порядок для сортировки, если это не B-tree | P10 |
| OpenTelemetry | Ограничение мощности множества меток метрик | P12 |
| Akeneo / Pimcore | Стабильная идентичность атрибута отдельно от его кода | P10 — `[UNVERIFIED]`, внешнее подтверждение не получено |

Подтверждение последней строки не получено; реестр не вправе выглядеть полнее фактов.
