## 2. Proposed canonical schema format 1

Identifier: `corex-template-schema/1`; format_version JSON integer 1. This is an internal proposed protocol, no new public Contracts. A signed manifest binds an exact PG16 minor/runtime, extension binaries/versions and serializer/extractor digest. Another major, unknown catalogue variant or unqualified minor/tool fails closed; format 1 does not promise cross-PG deparser equivalence.

Envelope keys: `embedding`, `extensions`, `format_version`, `modules`, `schemas`. All five required, unknown keys rejected. `embedding` has `model` string and `dimension` positive decimal string. `modules` is a unique ordered list of selected Composer module IDs (UTF-8 byte sort), with no source refs. `extensions` is ordered records of qualified `name`, `schema`, `version`; binary/source/tool provenance is separately signed. `schemas` contains ordered `{name,tables,sequences}` records. Duplicate identities, unknown relation/object kind, unknown extension or unaccounted dependencies reject the projection.

| Object | Semantic fields included | Ordering / catalogue source |
|:--|:--|:--|
| Schema/table | schema/name, ordinary-table kind, persistence, replica identity; RLS disabled requirement | schema/table name by UTF-8 bytes; pg_namespace/pg_class |
| Column | name, positive ordinal, qualified type plus typmod/dimensions, nullable, default expression or null, identity/generated mode, qualified collation plus actual version where applicable | ordinal position, preserving gaps; pg_attribute/pg_type/pg_attrdef/pg_collation |
| Constraint | name/kind, ordered columns, PK/unique NULLS policy, FK qualified target/ordered columns/match/update/delete actions, check expression, deferrable/initially_deferred/validated/no_inherit | name by UTF-8 bytes; pg_constraint; sequence of FK/key columns preserved |
| Index | name, access method, unique/primary/valid/ready flags, nulls-not-distinct, ordered keys/expressions, INCLUDE columns, qualified opclasses/collations, direction/null placement, predicate, semantic reloptions | name by UTF-8 bytes; pg_index/pg_am/pg_opclass + deparser; key order preserved |
| Sequence | qualified name/type, start/increment/min/max/cache/cycle and ownership table/column or null | name by UTF-8 bytes; pg_sequence/pg_depend, never last_value/is_called |
| Extension | approved name/schema/version | name by UTF-8 bytes; pg_extension; extension-owned dependency inventory bound by qualified extractor |

Initial allowlist: ordinary non-partitioned tables, their columns/PK/unique/FK/check/indexes, sequences, approved built-in/extension types/operators/opclasses and declared extensions. Views/materialized views, foreign/partitioned tables, user functions/procedures/triggers/rules/policies, standalone user types/domains/collations and other objects outside this list **reject**, including objects in an undeclared user schema. Supporting an additional object requires an explicitly approved projection/version; never drop it silently. Selected consumer modules are not yet named, so no claim that this allowlist covers their complete schema. The current tenancy migration scan includes ltree and GiST/expression/partial indexes; their exact extension/version must be qualified.

System objects are classified via a pinned pristine PG16 catalogue and extension membership, not just a broad schema-name filter. Include extension placement/version and validate its owned inventory against the approved extractor profile; unexpected changes reject. A clean known system/extension baseline is required; never treat an arbitrary object placed under pg_catalog as trusted. Missing baseline/unsupported extension inventory is an adoption blocker.

Exclude database name, owner, ACL, OID/physical identifiers, row counts/data, wall-clock timestamps, filesystem/tablespace environment paths, statistics and mutable sequence values. Column declarations named created_at/updated_at remain included; only observed timestamps are excluded. Default database collation's semantic provider/version must be resolved into affected column/index collation identities; environment location is not a schema semantic. ACL/owner/CONNECT/seal validity remains a separate admission invariant despite exclusion from hash.

Expressions use pinned PG16 `pg_get_expr(..., relation_oid, false)`, `pg_get_constraintdef(oid, false)`, `pg_get_indexdef(oid, 0, false)` and `format_type(type_oid, typmod)` with stable `search_path=pg_catalog`, UTF8 client encoding and pinned deparser/session settings. Resolve OIDs to qualified logical identities; no OID emitted. Never trim, collapse whitespace or rewrite literals. These functions reconstruct catalogue definitions rather than preserving original SQL: [PG16 system information functions](https://www.postgresql.org/docs/16/functions-info.html). Catalogue read uses one consistent read-only snapshot while the template lock is held.

Canonical JSON bytes: recursively sort object keys by UTF-8 bytes; no whitespace/BOM/trailing newline; UTF-8 strings without Unicode normalization; reject invalid UTF-8/lone surrogates and duplicate keys before parsing. Strings use JSON quotes/backslash escaping, short escapes for backspace/formfeed/newline/return/tab, lowercase `\u00xx` for remaining controls; slash, non-ASCII and U+2028/U+2029 remain literal UTF-8. Booleans/null are lowercase JSON tokens. Only format_version is a JSON number (integer 1); all catalogue integers are canonical decimal strings (`0` or optional minus plus nonzero-leading digits), no +/leading zeros, floats/NaN/exponents. Unknown scalars reject. Object arrays sort as specified above; columns and ordered index/FK keys never sort by name. Digest is SHA256 of exactly these bytes, encoded lowercase64.

def encode(value):
    def check(v):
        if isinstance(v, str):
            v.encode("utf-8")
        elif v is None or isinstance(v, bool):
            pass
        elif isinstance(v, int):
            if v != 1:
                raise ValueError("only format_version=1 is numeric")
        elif isinstance(v, list):
            for item in v: check(item)
        elif isinstance(v, dict):
            for key, item in v.items(): check(key); check(item)
        else:
            raise ValueError("unsupported scalar")
    check(value)
    return json.dumps(value, ensure_ascii=False, sort_keys=True,
                      separators=(",", ":"), allow_nan=False).encode("utf-8")
