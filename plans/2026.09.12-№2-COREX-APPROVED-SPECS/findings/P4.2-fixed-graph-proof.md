  unreleased prerelease constraints are exact.

  adds the two approved owned candidates, and changes the path package's two

`file://`/`path` transport in committed metadata. Thus a wrong source or
branch-metadata fixture cannot become a positive result.

## Commands and rollback

```bash
composer update corex/tenancy --with-all-dependencies --minimal-changes \
  --no-install --prefer-dist --no-interaction --no-plugins --no-scripts
composer --working-dir=packages/tenancy update \
  axiomasoft/stancl-tenancy axiomasoft/stancl-jobpipeline \
  --with-dependencies --minimal-changes --no-install --prefer-dist \
  --no-interaction --no-plugins --no-scripts
```

Both commands were executed with an isolated `COMPOSER_HOME` whose only extra
repository was a temporary `composer` repository containing copied P4.1 ZIPs
and metadata. Rollback restores the prior proven `stancl/*` requirements and
locks; it never substitutes a branch pin or changes a live database.
