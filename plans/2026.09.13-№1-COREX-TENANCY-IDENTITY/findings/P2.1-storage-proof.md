## Delivered boundary

- `TenantStorage` is the only new public contract. The boxed local adapter is
  scoped from `TenantContextResolver` to trusted
  `durable|ephemeral/tenants/{account-id}` roots and has no Stancl, auth,
  workspace, cloud, archive, or Flysystem-driver dependency.
- A `ScopedFilesystem` captures the account at handle creation, checks it for
  each filesystem operation, validates relative paths (including recursive URL
  decoding), rejects symlink components, and fails retained A handles after an
  A→B context switch.
- Local filesystem URLs are explicitly unavailable: Laravel's unconfigured
  local adapter would return `/storage/{relative-path}`, which does not encode
  this private tenant root and could therefore address a different disk.
- `usageBytes()` reports durable logical bytes, while export is explicitly
  unavailable via `StorageCapabilityUnavailable`.
