### P4.3 — Account-local membership projection и session revoke

**Intent:** Apply authenticated central membership state to one account and deny revoked tenant sessions.

**Why:** RAG:— 12h lifetime cap is not revoke SLA; delayed grant/revoke replay must not resurrect access.

**Scope Included:** Account-local projection Action, event job/observer, live-user guard integration, session deletion and replay tests.

**Scope Excluded:** Tenant root writes, central grant/accept/SSO writer, generic role policy, shared session store, new schema/credential fallback.

**Code Guidance:** 1. Authenticate event, resolve account and authoritative membership snapshot via qualified central transport; serialize account+identity updates so an old response cannot overwrite newer deny. If authority unavailable, deny/fail without regrant.

4. Crash/retry proof around projection commit, session deletion and event acknowledgement; duplicate event converges.
