## Честная граница этого артефакта

- Это захват текста ответа, не подписанный payload. SHA256 фиксирует файлы
  каталога после сохранения, не байтовую идентичность сетевому ответу.
- Длинные иллюстративные листинги сокращены до сигнатур с пометкой
  `[листинг сокращён]`; смысловые утверждения, имена механизмов и URL сохранены.
- Запросы формулировались нейтрально, без имени CoreX/FlexCRM, внутренних путей
  и ID (правило плана / PLAN1 D6). Первая попытка P2-Q3 завершилась таймаутом
  MCP; повтор успешен и сохранён.
- Известный дефект P1 (усечение ответа, начинающегося с таблицы) на этой фазе
  не воспроизведён: в каждый запрос входила явная просьба начать с прозы.
