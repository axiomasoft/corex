# Захват внешних ответов — детализация фазы P4

Шесть запросов Perplexity (MCP `perplexity · search`), 2026-09-19. Сводка с привязкой к
параграфам дизайна — `../../research/P4-design-rag.md`. Точные строки запросов, статусы,
первичные источники и SHA256 файлов захвата — `manifest.json`.

Границы захвата:

- Сохранён текст ответа из сессии; провайдер не отдаёт подписанный payload, поэтому SHA256
  фиксирует неизменность файла после сохранения, а не байтовую идентичность сетевому ответу.
- Длинные иллюстративные листинги сокращены до сигнатур с пометкой `[листинг сокращён]`.
  Смысловые утверждения, имена механизмов, значения по умолчанию и URL сохранены дословно.
- Формулировки нейтральны (D6 плана): ни имени CoreX/FlexCRM, ни внутренних путей, ни
  идентификаторов правил, ни схемы БД в запросах нет. Ответ подтверждает **общую практику**;
  вывод «поэтому в этом репозитории так» всегда локальный и несёт `RAG:—`.

| Файл | Запросы |
|:--|:--|
| `q01-q03.md` | P4-Q1 (PSR-20 Clock), P4-Q2 (версионированный durable-payload), P4-Q3 (утечки состояния в долгоживущем процессе) |
| `q04-q06.md` | P4-Q4 (tenant-идентичность в джобе), P4-Q5 (BC конструктора value object), P4-Q6 (часы приложения против часов БД) |

Известный дефект провайдера (с P1): ответ, начинающийся с таблицы, усекается. На P4 он
**воспроизвёлся один раз** — первый прогон P4-Q6 вернул только таблицу. Повтор с явным
запретом таблиц («Answer in continuous prose only») дал полный ответ; в `manifest.json`
это зафиксировано полем `retries`.
