### P10.1 — Module-free catalogue и composition

**Intent:** Сделать attributes работоспособными без modules через static-empty/static
definitions, сохранив текущие public ports и module integration.

**Why:** `P10-design.md` §2.2; D51. Текущий provider возвращает
`UnavailableAttributes` без двух module registries.

**Scope Included:** `StaticFieldCatalogue`; typed source/storage composition policy;
provider binding; additive config; unit tests без module bindings.

**Scope Excluded:** stable id semantics P10.2; DB source; rename
`RegistryFieldCatalogue`; package subsystem moves.

**Inputs:** `research/P7-design.md`;
`packages/attributes/src/AttributesServiceProvider.php`;
`packages/attributes/src/Contracts/FieldCatalogue.php`;
`packages/attributes/src/Contracts/AttributeStore.php`;
`packages/attributes/config/corex-attributes.php`.

**Files:** `packages/attributes/src/AttributesServiceProvider.php`;
`packages/attributes/src/Internal/Registry/StaticFieldCatalogue.php`;
`packages/attributes/src/Internal/Laravel/AttributeComposition.php`;
`packages/attributes/config/corex-attributes.php`;
`packages/attributes/tests/Unit/AttributesServiceProviderTest.php`;
`packages/attributes/tests/Unit/StaticFieldCatalogueTest.php`.

**Required Reads:** 1) `phases/P10/P10.md`; 2) `research/P10-design.md` §0–§2;
3) `decisions/D51-composite-catalogue-is-authoritative.md`;
4) `packages/attributes/src/AttributesServiceProvider.php`;
5) `packages/attributes/src/Contracts/FieldCatalogue.php`;
6) `packages/attributes/src/Contracts/AttributeStore.php`;
7) `packages/attributes/config/corex-attributes.php`;
8) `research/P7-design.md` § typed composition.

**Implementation Rules:** No new port. Empty static source yields an empty snapshot.
Module source is optional and appended only when registries are bound. Existing
`storage_driver` remains default. No runtime `config()` outside provider/composition.

**Code Guidance:** Use constructor-injected immutable maps; validate config once;
provider remains a thin binder. Exact semantics: `P10-design.md` §2.2.

**Validation:** Provider resolves usable catalogue/store with no modules; old module
case remains green; invalid source order fails; package lint/analyse/test.

**Deliverables:** Module-free binding, static source, typed composition and tests.
