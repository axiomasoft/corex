после cast/query evidence.

**Implementation Rules:** One entity→one engine; unknown/mixed fails. Existing global
driver is default. Index activation follows cast validation→EXPLAIN→concurrent queue→
verify. Names use id+revision; order includes record id.

**Code Guidance:** Facade partitions only `loadMany`; never reorders result. Promoted
is a declaration/integration seam, not an ALTER statement.

**Validation:** Both engines and mixed batch; invalid map red; dirty cast blocks DDL;
query uses verified B-tree with deterministic ordering; no foreign DDL.

**Deliverables:** Resolver/facade, index planner/policy, config and tests.
