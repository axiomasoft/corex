### P10.7 — Transactional mutation message

**Intent:** Зафиксировать mutation в P5 outbox без values и без зависимости на search.

**Why:** `P10-design.md` §9; D55. Projection должна быть durable и privacy-minimal.

**Scope Included:** internal domain event; explicit translator; v1 message contract;
registry extension; outbox append в store transaction; replay/rollback tests.

**Scope Excluded:** search consumer; ordering promise; raw values in payload; webhook.

**Inputs:** `phases/P10/P10.4.md`; `phases/P10/P10.6.md`;
`research/P5-design.md`; `decisions/D55-attribute-message-has-no-values.md`.

**Files:** `packages/attributes/src/Internal/Integration/AttributeValuesChanged.php`;
`packages/attributes/src/Internal/Integration/AttributeMessageTranslator.php`;

**Implementation Rules:** Append in same tenant DB transaction after mutation and before
commit. Replay appends nothing. Payload whitelist only; sorted ids/keys. Extend resolved
registry additively. No `CoreX\\Search` import.

**Code Guidance:** Domain event is internal; translator is the only mapping to public
message type. Consumer uses record version to converge, not delivery order.

**Validation:** One commit→one row; rollback→zero; replay→no duplicate; payload snapshot
has no values/PII; registry collision red; graph test zero search dependency.

**Deliverables:** Event/translator/contract registration, transactional wiring, tests.
