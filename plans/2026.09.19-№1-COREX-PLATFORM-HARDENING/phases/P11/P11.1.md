### P11.1 — Registry vocabulary, identity and version metadata

**Intent:** Закрепить типизированную identity каждой extension point, explicit
replacement directives, module version/reference metadata и общий `ExtensionStamp`.

**Why:** `research/P11-design.md` §2–§3, §5, §8; D56–D57. Текущий
compiler видит имена packages, но теряет version/reference и не имеет
общего словаря identity/replacement.

**Scope Included:** Additive `Manifest::replace()`; immutable replacement/version/stamp data;
version discovery from Composer metadata; point identity table in extension policy; focused tests.

**Scope Excluded:** Compile algorithm; cache publication; runtime freeze; durable consumer wiring;
new extension points; public registrar rename from P15.

**Inputs:** `packages/modules/src/Manifest.php`;
`packages/modules/src/Compiler/InstalledPackages.php`;
`research/P1-design.md` §10; `vendor/composer/installed.json`.

**Files:** `packages/modules/src/Manifest.php`;
`packages/modules/src/Compiler/ExtensionReplacement.php`;
`packages/modules/src/Compiler/InstalledPackageVersion.php`;
`packages/modules/src/Compiler/InstalledPackages.php`;
`packages/modules/src/Data/ExtensionStamp.php`;
`packages/modules/tests/Unit/ExtensionMetadataTest.php`;
`docs/architecture/extension-policy.md`.

**Required Reads:** 1) `phases/P11/P11.md`; 2) `research/P11-design.md` §0–§5, §8;
3) `decisions/D56-registry-authority-not-every-manager.md`;
4) `decisions/D57-point-specific-order-and-canonical-fingerprint.md`;
5) `packages/modules/README.md`; 6) `packages/modules/src/Manifest.php`;
7) `packages/modules/src/Compiler/InstalledPackages.php`;
8) `research/P1-design.md` §10.

**Implementation Rules:** Existing manifest methods and name-only discovery remain compatible.
Replacement is repeatable additive API with point/target/replacement only. `ExtensionStamp` has no
Laravel dependency and validates four non-empty scalars. No path, timestamp, tenant or activation
state is version metadata. Update the P1.6-produced policy; do not create a competing document.

**Code Guidance:** Implement the exact value shapes from §3/§5/§8. Resolve source reference
before dist reference, normalize missing values to explicit `null`, and use named arguments for
same-typed parameters.

**Validation:** Unit matrix for installed metadata, missing references, replacement accumulation,
stamp round-trip and invalid values; `composer lint`, `composer analyse`, `composer test` for
modules; docs identity table covers every §2 point.

**Deliverables:** Additive declaration primitives, version discovery, extension stamp, policy
vocabulary and green focused tests.
