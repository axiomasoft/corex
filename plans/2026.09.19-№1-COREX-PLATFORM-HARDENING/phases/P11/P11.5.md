### P11.5 — Versioned wakeup handler registry and stamped envelopes

**Intent:** Заменить raw `kind => class` на typed frozen handler definitions,
сохранять handler stamp в JSON envelope и fail closed до invocation.

**Why:** `research/P11-design.md` §8, §10; D59; D103. Текущий durable row пинит
только kind, поэтом deploy может молча подменить implementation уже
запланированной работы.

**Scope Included:** Typed definition/registry; legacy config parser; versioned `_corex` envelope;
digest over envelope; unwrapped public payload; exact stamp comparison; terminal stable mismatch
outcomes; read-only pending-row preflight command.

**Scope Excluded:** DDL; rewriting legacy rows; retrying incompatibility; automatic implementation
migration; consumer-specific payload fields; arbitrary runtime registration.

**Implementation Rules:** Compile/freeze definitions during provider composition; reject empty kind,
version, invalid handler and conflicts. Envelope is exactly §10; expose only `data` to handler.
Missing stamp is terminal unless that exact definition opts into bounded legacy admission. Version
mismatch is terminal `handler-version-mismatch`; missing is `handler-stamp-missing`; neither invokes
or retries. Canonical wakeup replay digest excludes `registryFingerprint`; provenance remains stored
and type-validated. A versioned identity schema preserves the comparison algorithm for legacy rows.
Preflight reads/reports only.

**Code Guidance:** Keep legacy scalar config as an explicit parser branch and emit a deprecation
signal; canonical config is structured. Persist the definition selected at schedule time, then
resolve and compare again at sweep time before constructing delivery.

**Validation:** Unit/feature/PG matrix covers structured/scalar config, duplicate/invalid definitions,
round-trip envelope, digest, exact match, fingerprint-only drift, missing/mismatched stamp, opt-in
legacy, no invocation/retry and read-only preflight; wakeup lint/analyse/test and isolated PG lane.

**Deliverables:** Frozen handler catalogue, versioned wakeup envelope, fail-closed replay and
operator preflight evidence without schema change.
