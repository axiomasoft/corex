# P11 — Модель расширения: typed registries, compile → frozen, durable stamps

## Phase Context

`RAG:—` В дереве уже есть правильная authority: `RegistryCompiler` →
`CompiledRegistry` → `CompiledModuleRegistry`. API/tool/panel/attribute catalogues — её
проекции; `SearchManager` — factory драйвера, а не registry. Пробелы:
`CompiledRegistry` shallow-readonly, `ArrayEntityRegistry` допускает late mutation,
duplicate/replacement policy нет, `InstalledPackages` теряет version/reference,
introspection считает второй hash.

`RAG:✅` Perplexity MCP и последующая проверка official Symfony/Laravel docs
подтвердили compile-before-use и long-lived application state. Queue workers
получают новый code через graceful restart, Octane — через reload; global
atomic fleet cutover не обещан. External evidence не определяет CoreX
identity/fingerprint/mismatch semantics: это локальные D56–D59.

> **Контракт фазы.** Потребляет: окончательную форму attribute catalogue P10,
typed composition P7, existing module lifecycle. Производит: один canonical
fingerprinted registry snapshot; point-specific identity/order/replacement; deep freeze;
request/job/deploy publication boundaries; exact extension stamps для workflow/wakeup;
contract suite и classification ratchet. Не вводит God Registry, новый DDL,
tenant-specific snapshots или девятую extension point.

> **Phase Assurance | v1.**
> Impact: internal-integration
> Integration Seams: module-extension-points · compiled-registry-cache · entity-projection · workflow-intent · wakeup-dispatch · long-running-workers
> Live or Irreversible: no
> Audit Intent: direct-close-eligible
> Rationale: fingerprint/freeze/replay semantics влияют на воспроизводимость;
> все восемь items имеют `full` review, P11.8 собирает final proof.

## Scope Included

Additive manifest replacement/version primitives; canonical compiler-private normal form; explicit
duplicate/replacement diagnostics; default lexical, declared-priority and menu topological ordering;
`corex-registry/1` fingerprint; scalar detached snapshot; entity collector freeze; authoritative
introspection; queue-job and Octane-deploy refresh contract; workflow stamp in existing payload;
typed/versioned wakeup handler map and envelope; read-only legacy preflight; fixes for tasks-workflow
materialization and notification digest consumers; reusable contract suite, ratchet gate, root
changelog and receipt.

## Scope Excluded

New extension points; rename `Extend`/`Gate` (P15); God Registry or public normal form; fake freeze
for `SearchManager`; replacement of P10 `schemaHash`; tenant-specific compiled artifacts; hot-swap
inside request/job; fleet-wide atomic deploy; generic extension FSM; workflow engine; DDL/backfill;
implicit legacy wakeup admission; API profile P13; external acceptance fixtures P17.

## Validation

Каждый item выполняет package `composer lint`, `composer analyse`, `composer test`;
DB-mutating lanes — только после test-isolation preflight. P11.8 дополнительно
прогоняет root checks и `composer test:pg` dependency closure. Обязательны negative
fixtures: duplicate owners, replacement errors/cycle, shuffled compile equality, corrupt snapshot,
late mutation, fingerprint/activation separation, workflow/wakeup version mismatch, missing stamp,
legacy opt-in, incomplete materialization payload, no handler invocation and unclassified new surface.
Пропущенный PG/consumer lane не считается green.
