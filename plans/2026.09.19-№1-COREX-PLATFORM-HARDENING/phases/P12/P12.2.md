### P12.2 — API error projection and internal correlation without wire change

**Intent:** Make API errors consume P12 descriptors and carry correlation internally
while preserving the exact pre-P12 serialized envelope and headers.

**Why:** `research/P12-design.md` §2; D61. P13 needs typed metadata as input, but it is
the sole owner of content negotiation and `operation-contract/1` snapshots.

**Scope Included:** Additive `ApiError` metadata; `DescribesError` mapping precedence; category→HTTP
defaults; safe framework fallbacks; valid/fallback correlation id; exact old-wire regression.

**Scope Excluded:** Emitting category/path/retryable/correlation; Problem Details; OpenAPI/errors
snapshot; changing existing error messages/statuses; operation observer.

**Inputs:** `phases/P12/P12.1.md`; `packages/api/src/ApiError.php`;
`packages/api/src/Internal/ErrorMapper.php`; `packages/api/src/Internal/EnvelopeSerializer.php`;
`packages/api/src/RequestMetadata.php`; `phases/P13/P13.md`.

**Files:** `packages/api/src/ApiError.php`; `packages/api/src/Internal/ErrorMapper.php`;
`packages/api/src/RequestMetadata.php`; `packages/api/src/Internal/EnvelopeSerializer.php`;
`packages/api/tests/Feature/ErrorBoundaryTest.php`;
`packages/api/tests/Unit/RequestMetadataTest.php`.

**Required Reads:** 1) `phases/P12/P12.md`; 2) `research/P12-design.md` §2;
3) `decisions/D60-error-descriptors-not-base-hierarchy.md`;
4) `decisions/D61-error-transport-stays-p13.md`; 5) `packages/api/README.md`;
6) `packages/api/src/ApiError.php`; 7) `packages/api/src/Internal/ErrorMapper.php`;
8) `packages/api/src/Internal/EnvelopeSerializer.php`; 9) `packages/api/src/RequestMetadata.php`;
10) `packages/api/src/ErrorBoundary.php`; 11) `phases/P13/P13.md`.

**Implementation Rules:** Append constructor parameters with defaults; preserve existing positional
calls. Explicit `ApiError` wins, then `DescribesError`, then framework mapping, then reported 500.
Never copy unknown exception message/details. Category default map is exactly §2. Validate both
ID headers identically; missing/invalid correlation falls back to request id. Do not modify serializer
body/header keys; the file is in Files only for the regression and any type adaptation required.

**Code Guidance:** Centralize descriptor→status in one private exhaustive `match`. `ApiError`
returns one `ErrorDescriptor` rather than duplicating validation. Test a synthetic package exception
implementing the interface; do not import attributes merely for the test.

**Validation:** Exact JSON/header snapshot before/after is identical; descriptor mapping covers all
nine categories; explicit status stays explicit; unknown exception reports once and leaks nothing;
valid correlation preserved, invalid/missing falls back; old 4-argument `ApiError` works. API
lint/analyse/test green. `rg` proves serializer exposes none of `category|retryable|correlation_id`.

**Deliverables:** Descriptor-aware mapper, compatible API error carrier, internal correlation and
wire-compatibility evidence for P13.
