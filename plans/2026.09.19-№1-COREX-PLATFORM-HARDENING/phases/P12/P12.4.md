### P12.4 — Vendor-neutral operation lifecycle and PSR-3 adapter

**Intent:** Define typed started/completed/failed events with one immutable
operation context, a no-op default and a safe structured PSR-3 projection.

**Why:** `research/P12-design.md` §4; D62. Long operations currently expose no
common duration/outcome/retry context, and raw exception logging would make the
contract unsafe and vendor-specific.

**Scope Included:** `OperationObserver`; context and three event DTOs; closed terminal outcomes;
identifier validation; null observer; static-message PSR-3 adapter; sequence/redaction tests.

**Scope Excluded:** OTel SDK, metrics, message trace propagation, automatic instrumentation;
SLO/alerts; forcing short CRUD calls through the observer.

**Inputs:** `phases/P12/P12.1.md`; `phases/P5/P5.2.md`;
`artifacts/P12-design-rag/P12-Q2-observability.md`.

**Implementation Rules:** Use exact fields/outcomes from §4. Started has event time; only terminal
events have duration. Attempt/duration cannot be negative. Failed adapter output includes only
code/category/path/retryability, never message, descriptor details or Throwable. Static log messages
are exact. Adapter failure cannot change the observed business outcome. No global/static current span.

**Code Guidance:** Events are final readonly. Reuse one private context-to-array projector inside
the PSR adapter. Preserve account/workspace/actor/operation ids in log context but mark them forbidden
for metrics in docblocks. Null adapter methods are explicit no-ops.

**Validation:** Valid start→complete and start→fail sequences retain identical context; invalid ids,
negative attempt/duration and unknown outcome fail. In-memory PSR logger sees exact static messages
and keys. A failure whose message/details contain a canary secret produces no canary. Null adapter
does not throw. Core lint/analyse/test green and P6 zone gate recognizes every new path.

**Deliverables:** Framework-neutral lifecycle contract, safe PSR-3 bridge, default null behavior and
redaction/sequence proof.
