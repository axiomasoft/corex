### P12.6 — Universal impersonation provenance on core audit entries

**Intent:** Stamp staff initiator, effective target, grant and reason at the
synchronous `AuditLogger::record()` seam for every audit producer.

**Why:** `research/P12-design.md` §7.1; D64. `AuditObserver` uses `CurrentActor`,
but callers that build `AuditEntry` directly bypass it; the queue worker is too late
to resolve the request/session safely.

**Scope Included:** Additive reason in state; immutable audit copy/enrichment; reserved context key;
universal enqueue-time stamp; CurrentActor parity; direct-caller and queued snapshot tests.

**Scope Excluded:** Tenancy session lifecycle (P12.7); audit DDL; changing queue/after-commit behavior;
logging reason to telemetry; changing non-impersonated actor semantics.

**Inputs:** `phases/P12/P12.1.md`; `packages/core/src/Tenancy/ImpersonationState.php`;
`packages/core/src/Contracts/AuditEntry.php`; `packages/core/src/Audit/QueuedAuditLogger.php`.

**Files:** `packages/core/src/Tenancy/ImpersonationState.php`;
`packages/core/src/Contracts/AuditEntry.php`;
`packages/core/src/Audit/QueuedAuditLogger.php`;
`packages/core/src/Audit/CurrentActor.php`;
`packages/core/tests/Feature/AuditImpersonationTest.php`.

**Required Reads:** 1) `phases/P12/P12.md`; 2) `research/P12-design.md` §7.1;
3) `decisions/D64-impersonation-audit-snapshot.md`;
4) `artifacts/P12-design-rag/P12-Q3-impersonation.md`;

8) `packages/core/src/Audit/CurrentActor.php`; 9) `packages/core/src/Audit/RecordAuditEntry.php`;
10) `packages/core/tests/Feature/DeliveryRemediationTest.php`.

**Implementation Rules:** Append optional reason to preserve constructor compatibility; real-service
non-null enforcement is P12.7. `withImpersonation()` overrides actor type/id and reserved context
from authority; caller cannot spoof it. Preserve unrelated context and then apply existing event-time/
workspace snapshot. Resolve state synchronously once. Queue worker must not resolve auth/session.
Reason stays in append-only audit only, never PSR/OTel metrics/logs.

**Code Guidance:** Compose immutable copy methods so either call order yields all fields, and test the
actual production order. Keep boxed `NullImpersonationService` behavior unchanged. Use a fake contract
binding, not a tenancy-package import.

**Validation:** Observer and direct logger entries under active impersonation both persist support/staff,
grant/target/reason, event time and workspace. Spoofed caller impersonation context loses to authority.
Normal user/system records are byte-equivalent. Queue worker with no session writes captured snapshot.
Core lint/analyse/test and audit after-commit regression green.

**Deliverables:** One complete audit stamp seam and proof that no public `AuditLogger` path can omit
impersonation provenance.
