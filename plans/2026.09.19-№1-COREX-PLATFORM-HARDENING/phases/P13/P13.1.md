### P13.1 — Compiled operation semantics and modes

**Intent:** Extend the existing module declaration/runtime projection with the
serializable semantics of `operation-contract/1` while preserving legacy declarations.

**Why:** `research/P13-design.md` §1; D65. Mode/scopes/idempotency/fields/pagination/
capability/deprecation must be compiler-visible, not inferred from HTTP methods or handlers.

**Scope Included:** Fluent declaration metadata; `OperationMode` and
`IdempotencyRequirement`; runtime projection and contract hash; compile validation;
legacy default matrix; bulk-mode fail-closed marker.

**Scope Excluded:** Invocation; profile/discovery; idempotency storage; cursor codec;
HTTP routes; snapshots; changing existing handler signature.

**Implementation Rules:** Keep `Api::operation()` positional compatibility; use exact
fluent metadata and validation matrix from §1. Compiler payload remains scalars/lists/maps.
Old declarations normalize to query for GET, command for mutation only when the existing
method permits it, with idempotency default forbidden/optional as specified by the explicit
compatibility fixture; no bulk execution is enabled. Contract hash uses canonical descriptor
plus upstream fingerprint and excludes activation/host/time.

**Code Guidance:** Add constructor arguments to `Operation` only at the end with defaults.
Use exhaustive enum matches in API projection; modules stores strings and does not depend on
`corex/api`. Normalize/sort scopes, capabilities and field lists before hashing; duplicate or
invalid entries fail compile with operation id and owner.
Idempotent mutation descriptors additionally declare the D104 effect mode: tenant-transactional,
same-transaction outbox intent, or an explicit reconciliation contract; direct external or
other-connection effects without one of those declarations fail compilation.

**Validation:** Existing declaration fixtures compile unchanged; reversed declaration order
has identical hashes. Plant every illegal mode/method/idempotency pair, duplicate field/scope,
bad capability/deprecation shape, unsafe idempotent effect mode and bulk default execution; each
fails at compile/projection.
Modules and API lint/analyse/test green.

**Deliverables:** Compiler-visible operation semantics, compatible runtime descriptor/enums,
deterministic `contractHash` and negative matrix.
