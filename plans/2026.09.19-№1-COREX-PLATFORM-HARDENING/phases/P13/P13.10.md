### P13.10 — Deterministic v1 contract snapshots

**Intent:** Generate and commit the installed-code v1 OpenAPI, operation, error and digest manifest
from one profile.

**Why:** `research/P13-design.md` §9; D73/S35. Deterministic runtime generation without a committed
baseline cannot prove compatibility to external clients.

**Scope Included:** Snapshot builder/command; canonical output; v1 OpenAPI/operations/errors/manifest;
P12 fixture consumption; repeat-generation and digest tests; build-time profile fixture.

**Scope Excluded:** Tenant-effective capability snapshot; webhooks.json before P14; compatibility
verdict (P13.11); client SDK generation; timestamps/host paths.

**Inputs:** `phases/P13/P13.3.md`; `phases/P13/P13.9.md`;
`phases/P12/P12.8.md`; `decisions/D57-point-specific-order-and-canonical-fingerprint.md`.

**Files:** `packages/api/src/Internal/ContractSnapshotBuilder.php`;
`packages/api/src/Commands/WriteApiSnapshots.php`;
`packages/api/src/ApiServiceProvider.php`;
`api/v1/openapi.json`;
`api/v1/operations.json`;
`api/v1/errors.json`;
`api/v1/manifest.json`;
`packages/api/tests/Feature/ContractSnapshotTest.php`.

**Required Reads:** 1) `phases/P13/P13.md`; 2) `research/P13-design.md` §9;
3) `decisions/D73-snapshots-pin-code-profile.md`; 4) `phases/P13/P13.3.md`;

**Implementation Rules:** Generator owns all `api/v1/*.json`; never hand-edit them. Exact contents/
exclusions from §9. Operations snapshot is behavioral authority; OpenAPI is projection; errors derive
from P12 fixture. Manifest hashes exact canonical bytes and includes no time/path/tenant/secret. Command
fails on dirty target unless explicit `--check` or atomic replace succeeds.

**Code Guidance:** Encode via `JsonCanonical` then pretty-print only through one deterministic helper
whose bytes are covered by test. Sort operations/errors/properties where semantic order is irrelevant.
Use a committed test profile assembled from module declarations, not live production tenant state.

**Validation:** Generate twice into temporary directories: byte-identical. Manifest SHA-256 matches
all three files; reverse module input same. Alter operation/error input changes expected digest. `--check`
passes current files and fails one-byte drift. No `webhooks.json`, host path, date, activation or secret.
API lint/analyse/test green.

**Deliverables:** Generator/command, four generated v1 carriers and reproducibility/digest evidence.
