### P13.3 — Immutable API profile, capabilities and deprecation catalogue

**Intent:** Build one deterministic code profile over the compiled registry while resolving
effective capability live from trusted context.

**Why:** `research/P13-design.md` §3; D67. Version, capability and deprecation need one
authority without hashing tenant activation into a second registry.

**Scope Included:** `ApiOptions`; API version/profile DTOs; capability/deprecation descriptors;
profile factory; deterministic fingerprint; redacted effective capability resolver contract;
configuration validation and tests.

**Scope Excluded:** Routes/controllers; deprecation headers; tenant-specific snapshots;
new registry lifecycle; licensing/entitlement source; P14 limits.

**Inputs:** `phases/P13/P13.1.md`; `research/P7-design.md`; `research/P11-design.md`;
`research/P12-design.md`.

**Files:** `packages/api/src/Support/ApiOptions.php`;

**Implementation Rules:** Provider is the only config reader; invalid profile fails at boot.
Profile is a sorted projection with no mutation methods. Fingerprint includes version/options
that affect public behavior, operation hashes and upstream registry fingerprint; excludes tenant,
activation, host path, time and secrets. Capability public map uses the allow-list in §3.2 and
never emits driver/class/connection/table/path. No entitlement reason without an authority source.

**Code Guidance:** Follow P7 `fromArray`/ViolationList pattern. Use final readonly DTOs and
canonical JSON. Keep `supportedThrough` a release-line string, not a calendar promise.
Deprecation descriptor validates absolute migration URI and ordered dates.

**Validation:** Reverse compiled order gives identical profile bytes/hash; activation toggles
effective capability but not profile hash. Invalid major/default/status/capability/deprecation,
secret in public map and infrastructure-key injection fail. API lint/analyse/test green.

**Deliverables:** Typed API options, deterministic profile/fingerprint, capability/deprecation
catalogues and redaction evidence.
