### P13.4 — Package routes, discovery and HTTP operation projection

**Intent:** Ship the complete HTTP surface from the explicitly installed provider, including
discovery, capabilities, OpenAPI and correct async/deprecation responses.

**Why:** `research/P13-design.md` §3.2–§4; D68; N07/S19/S31–S32. Handwritten host
wildcards are divergent and make the library incomplete as an API product.

**Scope Included:** Package route file/order/names; route opt-out/prefix/middleware; root
discovery; authenticated effective capabilities; current OpenAPI endpoint; wildcard operation;
202+Location; deprecation/sunset/link headers; README migration.

**Scope Excluded:** Content negotiation body (P13.9); public tenant capability leakage;
automatic provider discovery; host authentication implementation; bulk status lifecycle.

**Inputs:** `phases/P13/P13.2.md`; `phases/P13/P13.3.md`;
`packages/api/src/ErrorBoundary.php`; `packages/api/src/ApiController.php`;

**Implementation Rules:** Discovery routes precede wildcard and use stable names. Disabled
routes register none. Root discovery is code-profile only; capability requires resolved principal/
tenant and filters hidden operations. `ErrorBoundary` surrounds operation pipeline. Async response
requires validated `operation_id`/absolute-or-prefix-relative `status_url`; add one Location.
Deprecation headers derive only from descriptor and standards formats.

**Code Guidance:** One invokable/explicit-action controller may serve discovery actions but must
delegate profile/capability generation. Use Laravel route group with validated prefix/middleware;
do not call `config()` outside provider. Keep wildcard last and preserve method/path matching.

**Validation:** Route list exact with enabled/disabled/custom prefix; no duplicates across double
boot. Root response leaks no module/driver/class. Capabilities differ by activation/policy without
profile hash change. Forged tenant/workspace payload ignored. Async is 202+Location; sync unchanged.
Deprecation/Sunset/Link exact golden tests. Laravel package tests/lint/analyse green.

**Deliverables:** Package-owned opt-out routes, three discovery projections, async/deprecation
HTTP behavior and host migration documentation.
