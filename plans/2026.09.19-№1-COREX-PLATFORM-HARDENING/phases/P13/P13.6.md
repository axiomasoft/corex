### P13.6 — Idempotent operation invocation and replay

**Intent:** Decorate the shared invoker with deterministic fingerprint, one-effect execution and
semantic replay for HTTP and exposed tools.

**Why:** `research/P13-design.md` §5.1; D104; D105. A table alone does not prove admission order,
handler count or identical cross-transport outcomes.

**Scope Included:** Fingerprint/scope builder; idempotent invoker decorator; HTTP key normalization;
tool operation-key mapping; stored success/failure reconstruction; replay/conflict/in-progress errors;
full effect-count matrix.

**Scope Excluded:** Store DDL; standalone tool idempotency policies; unsafe automatic retry;
bulk lifecycle; exact HTTP-byte replay across media types.

**Implementation Rules:** Authenticate/authorize/validate before store begin. Required key missing
fails before handler; forbidden key on query is rejected, not ignored. Scope/fingerprint exact §5.1.
Only owner lease invokes inner handler. Mutation and success outcome commit in one tenant
transaction; external effects are outbox-only. Replay validates contract hash, invokes the
side-effect-free current-authority replay authorizer, applies denial/read pruning, and never invokes the handler.
Ambiguous commit maps to `reconciliation_required`; never infer retry from lease expiry,
Throwable/message, or a missing out-of-transaction terminal write.

**Code Guidance:** Decorator receives inner invoker, store, transaction boundary and replay authorizer.
There is no successful mutation outside the terminal-outcome transaction. Keep raw key out of logs/errors.

**Validation:** Same key/input over HTTP twice executes effect once. HTTP success then record/field
revocation then tool replay returns current denial/pruned outcome and handler count remains one.
Crash after mutation before terminal rolls back and retry commits once; ambiguous commit returns
`reconciliation_required` without a blind second effect; other input conflicts; concurrent request gets in-progress; validation/auth failure
creates no row; mapped 500 replays; contract hash mismatch fails; unknown post-effect store failure
inside the transaction rolls back. API lint/analyse/test + P13.5 PG lane green.

**Deliverables:** Shared idempotency decorator/fingerprint, two transport key adapters and complete
replay/concurrency effect-count proof.
