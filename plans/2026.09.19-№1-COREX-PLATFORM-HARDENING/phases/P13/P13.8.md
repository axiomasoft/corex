### P13.8 — Resource identifiers and five authorization layers

**Intent:** Make client scope, actor permission, record policy, field policy and tenant boundary
independent, and close the `onlyFields` bypass in both transports.

**Why:** `research/P13-design.md` §7; D105; D106; A99/A100/N08. Static metadata that is never applied
is a disclosure boundary, while broad OAuth scope cannot replace record/FLS checks.

**Scope Included:** `ResourceId`; client-scope and field-authorizer interfaces/defaults; shared
invoker ordering; declared write rejection/read pruning; recursive JSON-pointer policy;
HTTP/tool negative matrix and trusted-context forgery proof.

**Scope Excluded:** Generic record repository/policy; CRM-specific abilities; attribute eight-check
rewrite; inferring tenant from ResourceId; implicit CRUD.

**Implementation Rules:** Exact five-layer table from §7. Default scope authorizer allows empty
scope list and denies nonempty. Dynamic field policy may only narrow static declarations. Reject all
forbidden write paths before handler; recursively prune denied read paths before schema validation.
Legacy `fields($only)` on operation maps to both lists. Record and tenant ownership remain explicit
handler obligations and have negative fixture handlers.

**Code Guidance:** Validate `ResourceId` without database access against expected IdStrategy;
UUIDv7, UUID, ULID and positive-int forms round-trip canonically; type prefix is not authority.
Represent nested fields as RFC 6901 pointers and reuse P12 validation rules. Avoid silent write
filtering. Preserve list indexes when pruning output and fail safe on ambiguous structure.

**Validation:** Each layer denied independently while other four allow; client scope cannot bypass
actor/record/field/tenant. Forbidden write calls handler zero times; forbidden read value absent from
HTTP and tool output. Static list cannot be widened by host. Forged account/workspace/body ignored;
foreign ResourceId hidden per fixture. Default UUIDv7 plus UUID/ULID/int codec matrix round-trips and
rejects strategy mismatch. Revoked replay denies/prunes without a second handler call. API lint/analyse/test green.

**Deliverables:** Typed external id, two policy contracts/defaults, enforced field projection and
five-layer cross-transport evidence closing N08.
