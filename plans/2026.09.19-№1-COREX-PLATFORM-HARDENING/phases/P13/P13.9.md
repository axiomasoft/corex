### P13.9 — External error envelope and Problem Details

**Intent:** Expose P12 descriptors through the additive CoreX envelope and RFC 9457 content
negotiation without creating a second error vocabulary.

**Why:** `research/P13-design.md` §8; D72/D61. P12 intentionally kept wire bytes stable and
assigned category/path/retryability/correlation publication to P13.

**Scope Included:** Extended envelope/meta; Problem Details serializer; Accept negotiation/Vary;
problem type/instance; safe status/header policy; OpenAPI schemas; exact semantic parity tests.

**Scope Excluded:** New error codes/categories; parsing human message; arbitrary retry policy;
HTML errors; non-API exception handler; snapshot files (P13.10).

**Inputs:** `phases/P12/P12.1.md`; `phases/P12/P12.2.md`;
`phases/P13/P13.3.md`; `phases/P13/P13.4.md`.

**Implementation Rules:** Exact bodies and member naming from §8. Both representations consume
one mapped `ApiError/ErrorDescriptor`, have identical status/stable extensions/meta and never emit
raw exception/message/details. `application/problem+json` only when acceptable; default envelope
remains `application/json`. `Vary: Accept`, request id and no-store always. `Retry-After` only from
named bounded duration policy.

**Code Guidance:** Keep serializer implementations internal behind existing contract or an additive
contract if required; do not widen domain descriptor with HTTP fields. Use a deterministic problem
type URI builder from validated Options. OpenAPI declares both media types from shared schemas.

**Validation:** Golden envelope and Problem Details for every P12 category; same code/category/path/
retryability/details/request/correlation/version/status. Human message change leaves machine fixture
unchanged. Accept q-values/wildcards/unsupported 406; unknown exception safe/reported once; no raw
Throwable. Old success envelope unchanged except declared correlation addition. API lint/analyse/test.

**Deliverables:** Two negotiated representations over one descriptor, OpenAPI projection and
wire-parity/security evidence.
