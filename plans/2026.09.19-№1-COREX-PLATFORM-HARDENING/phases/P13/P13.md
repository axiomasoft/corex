# P13 — Внешний API как продукт: ядро контракта операций

## Phase Context

> СКЕЛЕТ — не детализирован, разворачивается `design-phase: task:plan-design 2026.09.19-№1-COREX-PLATFORM-HARDENING P13`

RAG:— `packages/api` (55 файлов) фактически является платформой вызова операций: реестр из
compiled-манифестов модулей, dispatcher, конверт `{data, error, meta}`, генератор OpenAPI 3.1,
каталог AI-инструментов и MCP-проекция. Но как **продукт** внешний API не оформлен: нет режимов
операции, нет idempotency-store на HTTP-пути, нет курсорной пагинации, нет профиля версии, нет
capability/discovery-эндпоинтов, нет committed snapshot'ов схемы, нет типизированного внешнего
идентификатора ресурса, `onlyFields` компилируется в метаданные, но диспетчером не применяется,
а маршруты пакет вообще не регистрирует — их монтирует приложение.

Несущее решение фазы — D2: версионирование мажором в пути плюс capability-negotiation;
date-based версии отклонены как основной механизм. Для self-hosted это не косметика:
RAG:✅ Atlassian прямо документирует, что ответы не помечаются версией API и клиент обязан
запрашивать capability, потому что доступная поверхность меняется вместе с установленными
плагинами — вплоть до изменения между запросами; GitLab держит `/api/v4` как долгоживущий мажор;
Grafana размечает зрелость alpha/beta/GA.

> **Контракт фазы (contract-first).** Потребляет: скалярный scope P4, Options P7, frozen-реестры
> P11, таксономию ошибок P12. Производит: `operation-contract/1` — режимы операции, профиль
> версии, capability/discovery, идемпотентность, курсорную пагинацию, внешний идентификатор
> ресурса, слои авторизации, расширенный конверт ошибок, регистрацию маршрутов, committed
> snapshot'ы схемы и CI-гейт их совместимости. Границы: бюджеты стоимости, bulk-операции и
> webhooks — P14; GraphQL не проектируется (D7).

> **Phase Assurance | v1.**
> Impact: public-contract
> Integration Seams: внешние клиенты и интеграции; MCP-инструменты; OpenAPI-документ;
> FlexCRM как потребитель; декларации операций в манифестах модулей
> Live or Irreversible: no (публикация контракта — под owner-gate)
> Audit Intent: direct-close-eligible
> Rationale: Стоимость ошибки внешнего контракта необратима для клиентов; Review всех items —
> `full`, заморозка `operation-contract/1` — owner-gate.

## Scope Included

Ответственность пакета одной строкой и словарь операции. Режимы операции (query, command,
async command, bulk query, bulk command) с разными гарантиями: query не меняет источник истины,
допускает кеш и курсорную пагинацию и не требует ключа идемпотентности; command проходит
семантическую авторизацию, поддерживает идемпотентность и оптимистичный параллелизм, публикует
события через транзакционную границу и пишет audit; async command возвращает приём с
идентификатором и адресом статуса, а не «200 c полем queued». Профиль версии как immutable
артефакт, компилируемый при bootstrap (та же механика compile→freeze, что в P11), вместо
ветвлений по версии в контроллерах и генераторах. Capability/discovery: метаданные установки,
список поддерживаемых мажоров, эффективные возможности для текущего токена и тенанта, документ
схемы; публичный ответ сообщает возможность, а не инфраструктуру (запрет раскрытия драйвера).
Депрекация: дескриптор устаревания как единый источник для OpenAPI, MCP-описаний, документации
и заголовков `Deprecation`/`Sunset`/`Link`; правило additive-first с закрытым списком
запрещённых изменений внутри мажора. Идемпотентность: store с состояниями, сохранение ответа
первого исполнения, конфликт при том же ключе с другим отпечатком запроса, отсутствие записи
при отказе валидации до начала исполнения, политика retention. Курсорная пагинация: подписанный
курсор, несущий версию формата, версию порядка, значения сортировки с обязательным
tie-breaker, привязку к аккаунту и отпечатку фильтров, срок жизни; порядок выбирается только из
серверного реестра, имена полей из курсора не принимаются. Типизированный внешний идентификатор
ресурса с префиксом типа. Слои авторизации: scope клиента, право актора, политика записи,
политика поля, граница тенанта — как пять независимых проверок; закрытие пробела `onlyFields`.
Расширение конверта ошибок кодом, категорией, путём и признаком повторяемости плюс
контент-негоциация `application/problem+json`. Регистрация маршрутов самим пакетом с
возможностью отключения. Committed snapshot'ы схемы на мажор и CI-гейт, отклоняющий удаление
операции или поля, добавление обязательного входа, смену типа и nullability, удаление значения
перечисления, смену стабильного кода ошибки и смену контракта пагинации.

Транспорт-нейтральность как проверяемое свойство: контракт операции не содержит
HTTP-специфичных допущений (метод, путь, статус-код и заголовки живут в адаптере), выбор полей
выражен параметром операции, авторизация поля проверяется в бизнес-слое на каждом пути обхода.
Доказательство — contract-тест: одна и та же операция вызывается из HTTP-адаптера и из
tool/MCP-поверхности без изменения контракта. Условия подключения будущего транспорта
фиксируются одним абзацем в `api-policy.md` — это весь задел под GraphQL (D7), отдельной
работы он не создаёт.

## Scope Excluded

Бюджеты стоимости и throttling, bulk-store, webhooks (P14); переименование пакета и классов
(P15); изменение декларативной модели модулей на статические методы класса (принято с
изменением: контракт достраивается поверх существующих манифестов); публикация split-зеркала.

GraphQL по D7 исключён полностью и явно: ни схемы, ни резолверов, ни адаптера, ни каталога
`GraphQL/`, ни зависимости на библиотеку GraphQL, ни упоминания в capability-ответе. Ни один
item фазы не несёт GraphQL в Deliverables.

## Dependencies

P4, P7, P11, P12 терминальны. Owner-gate G-API. Внутри фазы: словарь и режимы → профиль версии →
capability/discovery → идемпотентность → пагинация → идентификаторы → слои авторизации →
конверт ошибок → маршруты → snapshot'ы и CI-гейт.

## Validation (ожидаемая форма)

Оба лейна плюс `composer test:pg`. Contract-тесты из списка аудита: повтор идемпотентной команды
без второго эффекта; отказ на том же ключе с другим отпечатком; сохранение порядка при обходе
страниц курсором; недоступные поля не раскрываются; устаревшее поле доступно до версии
удаления; ошибки сериализуются стабильными кодами; старые snapshot'ы проходят против текущей
реализации. CI-гейт совместимости краснеет на каждом из семи запрещённых изменений
(контролируемо и обратимо). Детерминизм OpenAPI сохранён.
