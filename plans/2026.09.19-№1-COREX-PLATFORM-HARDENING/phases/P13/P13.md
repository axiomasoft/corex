# P13 — Внешний API как продукт: ядро контракта операций

## Phase Context

`RAG:—` `packages/api` уже имеет explicit module operations, trusted context,
deterministic OpenAPI, envelope и P11 tool/MCP projection. Но HTTP и exposed tools
вызывают handler через разные seams; mode/scopes/idempotency/pagination/deprecation
не входят в descriptor; `onlyFields` не применяется; routes и snapshots не
поставляются; compatibility gate отсутствует.

`RAG:✅` Perplexity comparative pass по GitHub, Slack, Twilio, HubSpot, Notion и
Contentful подтвердил: response-provided cursor не равен snapshot consistency;
retry не равен mutation idempotency; pinned OpenAPI не заменяет behavioral contract.
RFC 9745/8594/5829 ограничивают deprecation HTTP projection. Vendor-specific cadence,
limits и current version literals в CoreX не перенесены.

> **Контракт фазы.** Потребляет scalar scope P4, typed configuration P7,
> compiled/frozen registry P11 и error descriptor/correlation P12. Производит
> `operation-contract/1`: compiled operation semantics, one invocation boundary,
> immutable code profile + live capabilities, package routes/discovery,
> tenant-local idempotency, `api-cursor/1`, `ResourceId`, five authorization layers,
> dual error representations, committed v1 snapshots and compatibility gate.
> Budgets/bulk lifecycle/webhooks remain P14; GraphQL is absent by D7.

> **Phase Assurance | v1.**
> Impact: public-contract
> Integration Seams: module-compiler · operation-invoker · http-routes · mcp-tools · tenant-database · authorization · openapi-and-snapshots · external-clients
> Live or Irreversible: no
> Audit Intent: direct-close-eligible
> Rationale: P13.5 isolates G-DDL and P13.12 isolates G-API. All items are full-reviewed,
> cross-transport and compatibility ratchets run before contract freeze; no release occurs.

transport-neutral `OperationInvoker`; `ApiProfile` projection and typed API options;
live effective capability discovery; package-owned optional routes; async 202 + Location;

format/order versions; `ResourceId`; client/actor/record/field/tenant authorization matrix;

## Validation

Each item runs affected package lint/analyse/test. Module-compiler changes run modules
and api suites; idempotency runs SQLite behavior plus isolated tenant PostgreSQL lane;
route/error/profile changes test Laravel 12 and 13 package lanes already declared by
the package; final closure runs root Arch and package matrix.

Required negative evidence: illegal mode/method/idempotency; duplicate/non-deterministic
profile; route collision/disabled routes; tenant/actor payload forgery; same key/different
fingerprint; concurrent key and stale lease; tampered/wrong-scope/expired cursor; ordering
without tie-breaker; denied write and read field in HTTP and tool; Problem Details/envelope
semantic drift; raw exception leak; each of eight compatibility deltas; accidental GraphQL
file/string/dependency; second mutable API authority. Any skipped PG, parity, snapshot or
planted-gate lane is non-green.
