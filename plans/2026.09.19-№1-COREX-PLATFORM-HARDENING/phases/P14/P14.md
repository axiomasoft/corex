## Scope Included

Compiled cost recipes/pure estimator; shared SQL hierarchical reservation/refund;
observe/enforce/default global safety; HTTP/tool cost parity; bulk store/submit/poll/
cancel/result/failures; optional public transfer adapter, import resume/export restart,
cooperative cancellation/time/memory/source limits; declared webhook topics and PII;
transactional fan-out, immutable delivery bytes/id; signing/rotation; pinned HTTPS
SSRF policy; fenced retry/dead/history/replay; retention; typed wiring; snapshot gates;
package qualification, docs and single root changelog.

## Scope Excluded

GraphQL; billing; hard real-time preemption; universal exactly-once/ordering;
second transfer engine; arbitrary connector/factory discovery; remote test sends;
production migration/rollback, live secret rotation, deployment/tag/split publication;
P15 renames and P16 moves; generic cross-account scheduler (D48).
