### P15.2 — Attributes vocabulary

**Intent:** Rename `RegistryFieldCatalogue`→`ModuleFieldCatalogue`, `StructuralAttributeFilter`→`SchemaAttributeFilter`, `WriteResult`→`AttributeWriteResult`, `OperationKey`→`SchemaOperationId`.

**Why:** Имена должны отражать module ownership, schema boundary и предмет результата, не меняя семантику атрибутов.

**Scope Included:** Definitions, files, imports, types, named arguments, tests и public API metadata пакета attributes и прямых consumers.

**Scope Excluded:** Schema behavior, storage format, operation-id values, P3 naming gate implementation и aliases.

**Inputs:** `research/P15-design.md`; `decisions/D85-clean-rename-at-1-0-boundary.md`; `phases/P1/P1.3.md`; `phases/P9/P9.md`.

**Files:** `packages/attributes/src/**`; `packages/attributes/tests/**`; прямые consumer files; relevant Composer/public-api metadata.

**Required Reads:** 1) `phases/P15/P15.md`; 2) `research/P15-design.md`; 3) `decisions/D85-clean-rename-at-1-0-boundary.md`; 4) `phases/P1/P1.3.md`; 5) `phases/P9/P9.md`; 6) `docs/dev-doctrine.md`.

**Implementation Rules:** Сохранить signatures и value semantics; перемещать файл вместе с declaration; менять только доказанные references.

**Code Guidance:** Выполнить четыре mappings одним package lane, затем проверить reflection/string references отдельно от PHP imports.

**Validation:** attributes и consumer lanes green; strict PSR autoload; exact sweep четырёх old names пуст; public API manifest содержит только targets.

**Deliverables:** Четыре renamed definitions с обновлёнными consumers/tests и receipt completeness.
