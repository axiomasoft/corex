### P15.3 — Search unavailable provider

**Intent:** Переименовать `UnsupportedSearchProvider` в `UnavailableSearchProvider` во всём search package surface.

**Why:** Target описывает runtime availability, тогда как old name ошибочно обещает несовместимость capability.

**Scope Included:** Definition/file, throw/catch sites, imports, tests, docs snippets и public API metadata.

**Scope Excluded:** Provider selection logic, exception hierarchy, error text semantics и Meilisearch lane P15.4.

**Inputs:** `research/P15-design.md`; `decisions/D85-clean-rename-at-1-0-boundary.md`; `phases/P1/P1.3.md`; `phases/P10/P10.md`.

**Files:** `packages/search/src/**`; `packages/search/tests/**`; search docs/metadata; direct consumers.

**Required Reads:** 1) `phases/P15/P15.md`; 2) `research/P15-design.md`; 3) `decisions/D85-clean-rename-at-1-0-boundary.md`; 4) `phases/P1/P1.3.md`; 5) `phases/P10/P10.md`; 6) `docs/dev-doctrine.md`.

**Implementation Rules:** Preserve constructor and throw conditions; no compatibility alias.

**Code Guidance:** Use exact class-token inventory before move; distinguish prose “unsupported” from FQCN references.

**Validation:** search lint/analyse/test green; strict PSR autoload; old class token absent from runtime/tests/metadata; behavioral assertions unchanged.

**Deliverables:** Renamed provider exception and item receipt.
