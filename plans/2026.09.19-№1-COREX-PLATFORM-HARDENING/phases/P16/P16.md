# P16 — Раскатка профилей структуры по остальным пакетам

## Phase Context

P16 применяет правила P1 после семантических producer-фаз и P15. D91 исправляет устаревший
baseline скелета: API имеет явный post-P14 floor 155 файлов и идёт как профиль C тремя bounded
items; modules остаётся B при floor 99. D92 отделяет физическую структуру от публичной
идентичности: все post-P15 FQCN сохраняются через явные PSR-4 sub-prefix mappings. D93 оставляет
`corex/panels` компактным headless-пакетом, D94 завершает dev-only Testing boundary.

> **Контракт фазы (contract-first).** Потребляет: P1 profiles/policies; P2 inventory; P3 gates;
> terminal P6/P9/P10/P13/P14/P15 outputs. Производит: subsystem/context-first physical layout,
> FQCN-invariance receipts, dev-only package-local test harnesses, no-move proof профиля A,
> transfer growth map и итоговую qualification. Не производит: новый PHP vocabulary, DDL,
> runtime behavior, GraphQL, package creation/deletion или framework UI.

> **Phase Assurance | v1.**
> Impact: internal-integration
> Integration Seams: composer-psr4-resolution · package-public-surface · package-graph-and-phpstan-paths · package-local-test-autoload · ci-split-paths
> Live or Irreversible: no
> Audit Intent: direct-close-eligible
> Rationale: Механические move'ы обратимы и сохраняют FQCN; риск ложной зелени закрывают
> строгий autoload, byte-stable symbol manifests, package suites и planted negatives.

## Scope Included

no-move verdict panels; D33 Testing cleanup; profile-A proof и transfer growth map; Composer,
PHPStan, package graph, CI/split/docs/root CHANGELOG reconciliation; full positive/negative proof.

## Scope Excluded

Изменение FQCN/сигнатур/поведения; aliases/classmap/manual require; новые пакеты; DDL; package
identity decisions D89/D90; GraphQL; пустые или косметические каталоги; новые panel concepts;
per-package changelogs.
