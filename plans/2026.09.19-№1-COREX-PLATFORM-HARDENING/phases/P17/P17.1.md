### P17.1 — Frozen release cohort and deterministic candidate repository

**Intent:** Derive the post-P15 CoreX release cohort and build byte-reproducible package-only `1.0.0` dist archives plus Composer metadata.

**Why:** `research/P17-design.md` §2; D96. Hardcoded current package names can be stale after D89/D90, while every later P17 proof needs one identical artifact boundary.

**Scope Included:** Metadata/channel discovery; exclusion proof; deterministic export; dependency closure; local Composer repository; candidate manifest; wrong-file/path/non-determinism negatives.

**Scope Excluded:** Stability flip; product/test code changes; remote writes; tags/releases; fixture execution; publication authorization.

**Inputs:** `research/P17-design.md` §2; `decisions/D89-api-package-name.md`; `decisions/D90-auth-package-name.md`; `phases/P16/P16.13.md`; `scripts/distribution/remaining-cohort-policy.json`; `delivery/remaining-cohort-20260915/candidate.json`.

**Files:** `scripts/distribution/release-1.0-policy.json`; `scripts/distribution/release_candidate.py`; `scripts/distribution/tests/test_release_candidate.py`; `plans/2026.09.19-№1-COREX-PLATFORM-HARDENING/artifacts/P17/release-cohort.json`; `plans/2026.09.19-№1-COREX-PLATFORM-HARDENING/findings/P17-candidate-receipt.json`.

**Required Reads:** 1) `phases/P17/P17.md`; 2) `research/P17-design.md` §0, §2; 3) `decisions/D96-release-cohort-is-derived-and-pristine.md`; 4) `phases/P15/P15.11.md`; 5) `phases/P15/P15.12.md`; 6) `phases/P16/P16.13.md`; 7) `scripts/distribution/remaining-cohort-policy.json`; 8) `scripts/distribution/export-policy.json`; 9) `scripts/distribution/remaining-cohort-export.py`; 10) `docs/distribution-dry-run.md`.

**Implementation Rules:** Use exactly the schema/CLI/rules in §2. Discover identities from executed metadata, retain distribution visibility and include every live CoreX package exactly once. Export the committed candidate source, never arbitrary dirty bytes. No `version` field or path repository.

**Code Guidance:** Extend/reuse existing stdlib-only exporter primitives. Sort packages/files and canonicalize JSON. Build twice in separate temp roots; compare archive and metadata digests. Scan archive members and generated metadata for absolute/root/sibling paths.

**Validation:** Unit negatives for omitted/extra package, wrong channel, forbidden member, dependency gap, path leakage and one-byte nondeterminism. Two builds match. Every package passes `composer validate --strict --no-check-publish`; candidate repository resolves all exact `1.0.0` packages.

**Deliverables:** `corex-release-cohort/1`, deterministic local repository, candidate receipt and explicit exclusions for FlexCRM/tombstone with no external write.
