### P17.2 — External extension fixture matrix

**Intent:** Prove five extension families from standalone packages installed only against public candidate APIs.

**Why:** `research/P17-design.md` §3; D96; A14/A111. P11 provides an internal reusable suite but does not prove a real third-party package can compile, register and run after split export.

**Scope Included:** Search provider, attribute source, transfer codec, panel provider and workflow activity fixtures; P11 suite adapters; behavior checks; public-import and planted-Internal gates.

**Scope Excluded:** New CoreX contracts; internal imports; path repositories; production providers; GraphQL; changing a contract to accommodate a fixture.

**Inputs:** `phases/P17/P17.1.md`; `phases/P11/P11.8.md`; `phases/P1/P1.2.md`; `phases/P3/P3.3.md`.

**Files:** `fixtures/extensions/custom-search-provider/**`; `fixtures/extensions/custom-attribute-source/**`; `fixtures/extensions/custom-transfer-codec/**`; `fixtures/extensions/custom-panel-provider/**`; `fixtures/extensions/custom-workflow-activity/**`; `scripts/distribution/verify_extension_fixtures.py`; `scripts/distribution/tests/test_extension_fixtures.py`; `.github/workflows/distribution-proof.yml`.

**Required Reads:** 1) `phases/P17/P17.md`; 2) `research/P17-design.md` §0, §3; 3) `decisions/D96-release-cohort-is-derived-and-pristine.md`; 4) `phases/P17/P17.1.md`; 5) `phases/P11/P11.8.md`; 6) `research/P11-design.md` §12; 7) `phases/P1/P1.6.md`; 8) `scripts/package-graph-gate.php`.

**Implementation Rules:** Exact fixture roles/proofs are §3. Each is its own Composer package and `ThirdParty\\` namespace. Imports must be listed by the installed archive's API map. Contract-suite success never replaces the point-specific behavior assertion.

**Code Guidance:** Install the candidate repository into a new temp consumer per fixture. Run the framework-neutral helper, then one observable operation. Insert/remove the Internal import in `try/finally`; assert the diagnostic names both fixture and forbidden symbol.

**Validation:** Five clean installs, five P11 reports and five behavior probes green from original and reversed registration order. Missing candidate dependency and Internal import are red. No fixture autoload record contains the workspace.

**Deliverables:** Five standalone fixtures, one matrix receipt and CI coverage of DOD-20/DOD-24.
