### P17.4 — External bulk and webhook consumers

**Intent:** Prove the P14 async and outbound contracts from independent protocol consumers with bounded local adverse cases.

**Why:** `research/P17-design.md` §4. Internal integration tests do not prove a client can implement poll/cancel/result or verify/deduplicate signed webhook delivery from published contracts alone.

**Scope Included:** Bulk submit/poll/result/cancel/partial-failure client; webhook subscribe/signature/dedupe/replay client; published snapshots; local receiver; tamper/duplicate/expiry negatives.

**Scope Excluded:** Live external sends; production secrets; unbounded workload; GraphQL; new topic; provider code imports.

**Inputs:** `phases/P17/P17.1.md`; `phases/P14/P14.18.md`; `phases/P14/P14.20.md`.

**Files:** `fixtures/clients/bulk/**`; `fixtures/clients/webhook/**`; `scripts/distribution/verify_async_clients.py`; `scripts/distribution/tests/test_async_clients.py`; `.github/workflows/distribution-proof.yml`; `plans/2026.09.19-№1-COREX-PLATFORM-HARDENING/findings/P17-async-client-receipt.json`.

**Required Reads:** 1) `phases/P17/P17.md`; 2) `research/P17-design.md` §0, §4; 3) `phases/P17/P17.1.md`; 4) `phases/P14/P14.18.md`; 5) `phases/P14/P14.20.md`; 6) `research/P14-design.md` §4–§10, §13–§14; 7) `decisions/D80-delivery-identity-and-atomic-fanout.md`; 8) `decisions/D84-replay-retention-boundary.md`.

**Implementation Rules:** Exact protocol scenarios are §4. Use synthetic keys and local receiver only. Bulk client accepts partial completion and opaque result URLs. Webhook signs/verifies exact bytes, deduplicates on delivery identity and never infers a Laravel class from topic.

**Code Guidance:** Run clients as separate processes against an installed candidate app. Control time with the test clock. Corrupt one signature byte and replay one delivery id; prove no client side effect before/after rejection respectively.

**Validation:** Full bulk lifecycle and one row failure pass; cancellation preserves completed effects. Webhook exact signature passes, tamper fails, duplicate is idempotent and bounded replay obeys retention. Snapshot mismatch and undeclared topic fail before action.

**Deliverables:** Bulk/webhook fixtures and adverse-case receipts without live egress.
