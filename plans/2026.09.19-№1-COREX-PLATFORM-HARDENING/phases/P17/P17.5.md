### P17.5 — Independent equipment-registry consumer

**Intent:** Build a useful Laravel consumer with no Flex/CRM/CMS/Store dependency or vocabulary, using the same public lower-level contracts as FlexCRM.

**Why:** `research/P17-design.md` §5; D95/D96. FlexCRM alone cannot prove level-0 agnosticism.

**Scope Included:** Candidate-only install; entity/module, attributes, base search, transfer, workflow/wakeup and optional operation use; behavior smoke; forbidden-vocabulary/import scan.

**Scope Excluded:** Product-quality UI; CMS/content/store/CRM feature; Flex package; Meilisearch; CoreX code changes; private/internal API.

**Inputs:** `phases/P17/P17.1.md`; `phases/P4/P4.11.md`; `phases/P10/P10.8.md`; `phases/P11/P11.8.md`; `phases/P13/P13.12.md`; `phases/P14/P14.20.md`; `packages/crm/composer.json`.

**Required Reads:** 1) `phases/P17/P17.md`; 2) `research/P17-design.md` §0, §5; 3) `decisions/D95-dod-is-twenty-five-plus-two-plan-assertions.md`; 4) `decisions/D96-release-cohort-is-derived-and-pristine.md`; 5) `docs/dev-doctrine.md` §1; 6) `phases/P11/P11.8.md`; 7) `phases/P13/P13.12.md`; 8) `phases/P14/P14.20.md`; 9) `packages/crm/composer.json` only for lower-level dependency comparison.

**Validation:** Fresh install boots; complete equipment behavior flow passes across a worker restart; public-import and forbidden-vocabulary scans green. Remove Modules or Search Intl only in P17.6; an Internal import and a `flex/crm` dependency each fail.

**Deliverables:** Independent consumer and receipts for DOD-19/DOD-27.
