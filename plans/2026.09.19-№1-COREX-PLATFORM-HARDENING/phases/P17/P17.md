# P17 — Доказательства универсальности и Definition of Done 1.0

## Phase Context

> СКЕЛЕТ — не детализирован, разворачивается `design-phase: task:plan-design 2026.09.19-№1-COREX-PLATFORM-HARDENING P17`

RAG:— Финальная фаза доказывает то, что план обещает: CoreX полезен проекту без CRM и CMS, его
расширения пишутся снаружи и только по публичному API, а обновление с предыдущей поддерживаемой
версии проверяется. Сегодня в дереве нет ни одной внешней фикстуры расширения и ни одного
не-CRM потребителя: универсальность доказывает только FlexCRM, а зелёный monorepo CI не является
доказательством корректности отдельно установленного пакета.

Фаза не создаёт новых возможностей. Она создаёт доказательства и закрывает 1.0 гейтом из 27
условий Definition of Done, каждое из которых к этому моменту должно иметь владельца и
проверку в предыдущих фазах.

> **Контракт фазы (contract-first).** Потребляет: результаты всех фаз. Производит: внешние
> фикстуры расширений на публичном API, минимальный не-CRM потребитель, матрицу профилей
> установки, доказательство пути обновления, финальный scorecard, исполняемый гейт DoD 1.0 и
> release-гейт. Границы: не добавляет новых возможностей; обнаруженный дефект возвращается
> фазе-владельцу, а не исправляется как «мелочь» внутри приёмки.

> **Phase Assurance | v1.**
> Impact: public-contract
> Integration Seams: split-mirror-publication · release-tag · installation-profiles
> Live or Irreversible: yes
> Audit Intent: direct-close-eligible
> Rationale: Тег 1.0 и публикация split-зеркал необратимы и выполняются только под G-RELEASE. Приёмка коммерческого обещания; Review всех items — `full`, публикация — owner-gate
> G-RELEASE.

## DoR (Definition of Ready)

- [ ] Все `[NEEDS CLARIFICATION]` сняты.
- [ ] Каждое из 27 условий DoD 1.0 имеет владельца (фазу) и конкретную проверку.
- [ ] Owner-gate G-RELEASE объявлен; до него публикация и теги запрещены.
- [ ] Профили установки перечислены точно, включая профиль без модульной системы.
- [ ] Каждая item-спека называет параграф `research/P17-design.md` с готовым кодом фикстур.
- [ ] Ни один item не превышает бюджет 200K.

## Scope Included

Внешние фикстуры расширений, использующие только публичный API: сторонний провайдер поиска,
сторонний источник определений атрибутов, сторонний кодек переноса, сторонний поставщик панелей,
сторонняя активность workflow; каждая проходит contract suite из P11. Consumer-фикстуры внешнего
API: REST-клиент, MCP-клиент, потребитель webhook, клиент bulk-выгрузки (без GraphQL по D7);
каждая использует только опубликованные схемы. Минимальный не-CRM потребитель как доказательство
теста агностичности. Матрица профилей установки: single-tenant, multi-tenant, только
CLI/воркер, без Meilisearch, без модульной системы там, где это допустимо; каждый профиль
поднимается из чистой установки. Доказательство пути обновления с предыдущей поддерживаемой
версии. Финальный scorecard по 12 критериям с объяснением каждой оценки ниже максимума.
Исполняемый гейт DoD 1.0: 27 условий как проверки, а не как чек-лист в документе. Release-гейт:
BC-дифф, snapshot'ы схемы внешнего API, CHANGELOG'и, теги, публикация split-зеркал.

## Scope Excluded

Новые возможности; исправление дефектов, найденных приёмкой, внутри этой фазы (возвращаются
фазе-владельцу); публикация до owner-gate G-RELEASE; фикстура GraphQL-клиента (D7);
продуктовые вехи FlexCRM.

## Dependencies

Все фазы P1–P16 терминальны. Owner-gate G-RELEASE. Внутри фазы: фикстуры расширений →
consumer-фикстуры → не-CRM потребитель → матрица установок → путь обновления → scorecard →
гейт DoD → release.

## Validation (ожидаемая форма)

Полный корневой контур плюс `composer test:packages`, `composer test:pg`,
`composer package-graph-gate`, `composer test:arch`, гейт публичной поверхности, BC-дифф, гейт
совместимости схемы внешнего API, `bash scripts/anti-weakening-gate.sh`,
`bash scripts/mutation-check.sh --all`. Каждая фикстура собирается и проходит contract suite из
чистой установки, а не из монорепо-автолоада. Каждый профиль установки поднимается и отвечает.
Путь обновления воспроизводится наблюдаемо. Гейт DoD 1.0 зелёный по всем 27 условиям; любое
красное условие возвращается фазе-владельцу и блокирует тег.
