# P2 — Машинная инвентаризация: файлы, символы, графы, таблицы, конфигурация

## Phase Context

RAG:— Фаза заменяет ручные оценки измеримой базой. В репозитории нет ни файлового
инвентаря, ни сохранённого графа импортов (гейт строит его внутри себя), ни
документа владения таблицами, ни карты конфигурационных ключей. Без этого
«разделить core» и «зафиксировать public API» остаются намерениями.

Все артефакты фазы — read-only производные: они не меняют поведения и
перегенерируются своим генератором. Рукописных копий таблиц нет.

Владение путями: сканер и CSV/JSON — **плановые**
(`plans/<PLAN-ID>/scripts/architecture/`, `plans/<PLAN-ID>/artifacts/architecture/`).
Три документа — `docs/architecture/table-ownership.md`,
`docs/architecture/configuration.md`, `docs/architecture/scorecard.md` —
**продуктовые**: шапка ссылается на статьи P1, таблица генерируется из плановых
артефактов. Корневой `artifacts/` (вывод гейта графа) фаза не трогает.

Два инварианта фазы (D15, D16): измерение и суждение — разные файлы; сканер —
stdlib `token_get_all` без новой зависимости Composer. Самопроверка обязана
воспроизвести числа `00-baseline-metrics.md` (888 / 152 / 0 / 19×188 / 86);
расхождение без объяснения — дефект сканера.

`RAG:✅` три графа — разные вопросы, необъяснённое расхождение — долг
(`research/P2-design-rag.md` §1, P2-Q2). `RAG:✅` каталог таблиц именует владельца
по возможности, не по префиксу (P2-Q3 / P1-Q4). `RAG:✅` scorecard — fitness
function, не KPI (P2-Q5).

> **Контракт фазы (contract-first).** Потребляет: таксономию, профили и определение
> публичности из P1 (`research/P1-design.md`; в стадии 3 — уже записанные
> `docs/architecture/{constitution,taxonomy,structure-profiles,api-policy}.md`).
> Производит: `files.csv` (21 колонка), `symbols.csv`, три графа и отчёт
> расхождений, `table-ownership.md`, `configuration.md`, `verdicts.csv`, базовый
> scorecard. Границы: ничего не исправляет; найденный дефект — вход
> фазы-владельца.

> **Phase Assurance | v1.**
> Impact: isolated
> Integration Seams: inventory-to-gates · inventory-to-core-zones · inventory-to-rename-rollout
> Live or Irreversible: no
> Audit Intent: direct-close-eligible
> Rationale: Артефакты read-only и детерминированно перегенерируемы; ошибка
> сканера видна сравнением с `research/00-baseline-metrics.md`. Residual risk
> без owner-bound audit-admission остаётся рекомендацией.

## Scope Included

Файловый инвентарь по всем `packages/*/src` с 21 колонкой измерения (§2.1
дизайна). AST-подобный разбор `use` (alias, group) на `token_get_all`.
Пер-символьный ряд (`symbols.csv`) с `certainty`. Три графа и классификация
расхождений, включая слепое пятно `parseUseImport` гейта. Реестр таблиц по всем
`Schema::create` в миграциях пакетов с разрешением разделённого
`sys_` (N10). Реестр ключей конфигурации, включая сохранённый `corex-intl-search`
(N11). Пер-классовые вердикты как отдельный артефакт (D15). Базовый scorecard
20 пакетов × 12 критериев без среднего балла.

## Scope Excluded

Любое исправление найденного; переносы и переименования; правка провайдеров и
конфигурации; создание гейтов (P3); изменение `scripts/package-graph-gate.php`;
новая зависимость Composer; ручное заполнение таблиц, которые обязан произвести
генератор; догадка в поле `unobserved`; запись в корневой `artifacts/`.

1. `php plans/2026.09.19-№1-COREX-PLATFORM-HARDENING/scripts/architecture/bin/inventory.php inventory`
   завершается кодом 0; `self-check.json` имеет `"ok": true` на шести ключах базы.
2. Повторный прогон даёт байтово идентичные `files.csv` и `symbols.csv`
   (`cmp` без отличий).
3. `files.csv` содержит ровно 21 заголовок §2.1 и не содержит `verdict`.
4. `discrepancies.md` содержит все шесть кодов §4.4 хотя бы как заголовки секций;
   секция `G-GATE-BLIND` называет целое число.
5. В `table-ownership.md` у каждой таблицы Schema::create из миграций
   пакетов (каталог database/migrations) есть ровно один
   владелец-пакет; префикс `sys_` не выступает владельцем.
6. `configuration.md` содержит ключ `corex-intl-search` с отсылкой к CFG-006.
7. `git diff --stat -- 'packages/*/src' 'packages/*/database' 'scripts/package-graph-gate.php' 'tests' '.github'`
   пуст.
8. `composer lint:check` из корня — зелёный (случайная правка PHP продукта).
