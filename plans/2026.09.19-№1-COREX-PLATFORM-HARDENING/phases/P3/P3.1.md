### P3.1 — Контур PHPStan по currently-green пакетам (N03)

**Intent:** Измерить `composer analyse` всех 20 живых пакетов, добавить в
корневой `phpstan.neon` только уже зелёные и закрепить JSON-контур, чтобы
N03 больше не был «7 из 21».

**Why:** `RAG:—` корневой neon анализирует api/core/crm/tasks/modules/tenancy/workflow.
Пакетные `analyse`-скрипты есть, но корневой job и N03 смотрят только
семь путей. Baseline.neon запрещён анти-ослаблением. N02 опровергнут: корневой цикл пакетных тестов уже полон, отдельные test-джобы
recurrence/meilisearch не возвращаются (`research/P1-design.md` §12).

**Scope Included:** CLI `scripts/phpstan-contour.php`; артефакт
`plans/2026.09.19-№1-COREX-PLATFORM-HARDENING/artifacts/architecture/phpstan-contour.json`;
правка `parameters.paths` корневого `phpstan.neon`; корневой
`composer.json` (скрипт контура PHPStan); негативная посадка в core;
строка CHANGELOG; append receipt.

**Scope Excluded:** Починка красных пакетов (долг JSON, не P3); phpstan-baseline;
понижение level; пакеты `import-export`; изменение `phpstan-tests-lint.neon`;
новые CI test-джобы; повторное расширение корневого цикла пакетных тестов.

**Inputs:** `research/P3-design.md` §0, §3 как нормативная спецификация
алгоритма и формы JSON; корневой `composer.json`; текущий `phpstan.neon`.

**Files:** `scripts/phpstan-contour.php`; `phpstan.neon`; `composer.json`; `plans/2026.09.19-№1-COREX-PLATFORM-HARDENING/artifacts/architecture/phpstan-contour.json`; `CHANGELOG.md`; `plans/2026.09.19-№1-COREX-PLATFORM-HARDENING/findings/P3-gate-receipts.md`

**Required Reads:** 1) `plan.md` §2 Execution Rules; 2) `phases/P3/P3.md`; 3) `research/P3-design.md` §0, §3; 4) `research/P1-design.md` §12 (N02/N03); 5) `phpstan.neon`; 6) `composer.json` (корневые scripts analyse и цикл пакетных тестов); 7) `.github/workflows/ci.yml` job `quality`; 8) `scripts/anti-weakening-gate.sh` (запрет baseline); 9) `findings/audit-verdicts.md` N03.

**Implementation Rules:** Код CLI переносится из §3.1–§3.3 по смыслу
дословно: схема JSON `phpstan-contour/1`, без `generated_at`, сортировка
по `dir`. В корневой neon попадает только `pass=true`. Красный пакет —
строка `debt`, не baseline. Негативная посадка удаляется в `finally`.
Ни один файл вне `Files` не изменяется. Ширина PHP ≤ 120.

**Code Guidance:** Алгоритм и форма JSON — `research/P3-design.md` §3.
Негатив — §3.2 (`PhpstanContourProbe.php`). Не добавлять в neon пакет,
который пакетный `analyse` не прошёл: это превратит item в скрытый
ремонт всех пакетов.

**Validation:** `php scripts/phpstan-contour.php` код 0. JSON содержит 20
живых имён. Каждый `pass=true` встречается в `phpstan.neon` как path.
`composer analyse` зелёный. Посадка Probe: `composer analyse` ≠ 0 и
содержит `PhpstanContourProbe.php`; файл отсутствует после теста.
`bash scripts/anti-weakening-gate.sh` зелёный. `composer lint:check`
зелёный.

**Deliverables:** контурный CLI и JSON; расширенный корневой neon только
на currently-green; receipt с таблицей pass/debt и выводом негатива.
