### P5.14 — Make wakeup clock composition package-safe

**Intent:** Make `WakeupServiceProvider` resolvable without `CoreServiceProvider` while preserving
an application-provided PSR-20 clock.

**Why:** EA01 reproduces three notifications package errors because wakeup resolves an interface
whose only binding currently lives in another provider's composition.

**Scope Included:** package-internal system clock; conditional default binding; focused wakeup and
notifications witnesses; CHANGELOG and receipt.

**Scope Excluded:** clock semantics of core; database/server time; retries or lease policy;
requiring notifications to load CoreServiceProvider; new dependencies.

**Inputs:** `research/P4-P5-execution-remediation.md` §3; `phases/P4/P4.9.state.md` (producer: P4.9); `phases/P4/P4.10.state.md` (producer: P4.10); `findings/execution-audit-P1-P5-2026-09-22.md` EA01.

**Files:** `packages/wakeup/src/Internal/SystemClock.php`; `packages/wakeup/src/WakeupServiceProvider.php`; `packages/wakeup/tests/Feature/WakeupSchedulerTest.php`; `packages/notifications/tests/Feature/DigestWakeupAdapterTest.php`; `CHANGELOG.md`; `plans/2026.09.19-№1-COREX-PLATFORM-HARDENING/findings/P5-remediation-receipts.md`

**Required Reads:** 1) `phases/P5/P5.md`; 2) `research/P4-P5-execution-remediation.md` §3; 3) `findings/execution-audit-P1-P5-2026-09-22.md` EA01; 4) `phases/P4/P4.9.state.md`; 5) `phases/P4/P4.10.state.md`; 6) `packages/wakeup/src/WakeupServiceProvider.php`; 7) `packages/core/src/Support/Time/SystemClock.php`; 8) `packages/notifications/tests/TestCase.php`; 9) `packages/wakeup/composer.json`.

**Implementation Rules:** Bind a wakeup-internal `ClockInterface` implementation only when the
container has no binding. A pre-bound `FrozenClock` must remain identical. Do not consume a
non-public core Support symbol. Use `DateTimeImmutable` in UTC and satisfy PSR-20.

**Code Guidance:** Follow §3. Prefer Laravel container `bound()`/conditional registration; do not
overwrite host composition. Add explicit witnesses for standalone resolution and preserved override.

**Validation:** wakeup `test` and `test:pg`, notifications `test`, root `composer test:packages`,
`composer analyse:packages` and `composer package-graph-gate` pass for the changed delta. Pint passes.

**Deliverables:** standalone-safe wakeup clock composition; override witness; notifications
regression witness; CHANGELOG and receipt.
