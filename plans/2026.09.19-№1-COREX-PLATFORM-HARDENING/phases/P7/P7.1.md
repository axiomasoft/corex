### P7.1 — Шаблон Options, SecretRef, CoreOptions, Config::bind

**Intent:** Ввести `ViolationList`, `InvalidConfiguration`, `SecretRef`,
`CoreOptions::fromArray` и превратить `Support/Config` в holder над
связанным снимком; перевести `SqlSavedViewRepository` на конструктор.

**Why:** N12/A76: 31 `config(` в одном статическом аксессоре. `RAG:✅`
P7-Q1: фабрика без `config()` тестируется без контейнера. D39: модели
и миграции оставляют `Config::`. D40: три пути redaction плюс
`SensitiveParameter`.

**Scope Included:** классы §3–§5; bind/unbind/options; override
octane-worker (§15); биндинг в `CoreServiceProvider`;
`SqlSavedViewRepository`; строка CHANGELOG. Фокусные behavior-доказательства
D100 и receipt вынесены в P7.12, чтобы этот product-item остался в лимите
восьми Files.

**Scope Excluded:** инъекция `CoreOptions` в модели, миграции, audit,
pubsub, departments; Options других пакетов; команда validate (P7.10);
гейт (P7.11); смена ключей.

**Inputs:** `research/P7-design.md` §0, §3–§5, §15; `research/P7-design-rag.md`
§1 (P7-Q1, P7-Q2); D39, D40, D100, D101; `packages/core/config/corex.php`.

**Files:** `packages/core/src/Support/ViolationList.php`; `packages/core/src/Support/InvalidConfiguration.php`; `packages/core/src/Support/SecretRef.php`; `packages/core/src/Support/CoreOptions.php`; `packages/core/src/Support/Config.php`; `packages/core/src/CoreServiceProvider.php`; `packages/core/src/Views/Internal/SqlSavedViewRepository.php`; `CHANGELOG.md`

**Implementation Rules:** Код §3–§5 с коррекцией D100: `cache_ttl` читается через
`array_key_exists` (missing=3600, explicit null=null); хелперы `fromArray` —
в том же файле `CoreOptions` по контракту §5.1. По D101 exact-путь
`packages/core/src/Support/CoreOptions.php` — COMPOSITION: его defaults могут
импортировать объявленные типы разных зон; это не меняет
`ALLOWED['Foundation']` и не разрешает другие `Support/*`. `config()` исчезает из
`Config.php` и из `SqlSavedViewRepository`. Repository хранит только explicit
connection override; при null каждую операцию берёт current default из injected
DB manager и не фиксирует mutable default в singleton. Аксессор
`pubsubOctaneWorkerOptIn` использует override §15, не повторный
`config()`. Соединение views резолвит провайдер. Ни один файл вне
`Files` не изменяется. P7.1 не пишет receipt и не изменяет тесты;
эти writes принадлежат P7.12.
