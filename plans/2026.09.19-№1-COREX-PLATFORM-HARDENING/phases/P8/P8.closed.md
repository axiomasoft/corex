# Закрытие фазы P8

> Не править руками: это генерируемый вид.

## Контракт фазы

**Контракт фазы (contract-first).** Потребляет: Options P7. Производит:
`PackageRegistrar`, декомпозицию tenancy и modules, каталог биндингов
«до», гейт размера провайдера. Границы: поведение не меняется — ключ,
класс реализации и lifetime биндинга совпадают; порядок bootstrapper'ов
байтово тот же; Membership не получает пустой registrar; Core не
дробится.

## Произведено

- P8.1 — Контракт PackageRegistrar, каталог биндингов, правило модуля: интерфейс и trait; каталог «до»; правило модуля;
- P8.2 — Tenancy: Runtime, Database, Provisioning: три registrar'а; провайдер вызывает их; тесты lifetime;
- P8.3 — Tenancy: Identity, Workspace, DomainTrust, Authentication, Wakeup: пять registrar'ов; условное включение; тесты обоих
- P8.4 — Tenancy boot: Console, Http, Events; порядок bootstrapper'ов: три boot-registrar'а; проекция stancl в Runtime boot;
- P8.5 — Декомпозиция ModulesServiceProvider: четыре registrar'а; провайдер без call site биндингов;
- P8.6 — Гейт порога размера провайдера: блокирующий гейт; снимок ratchet; доказанная посадка;
