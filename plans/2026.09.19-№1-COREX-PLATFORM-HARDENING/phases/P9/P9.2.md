### P9.2 — Runtime и Laravel boundary

**Intent:** Собрать runtime tenancy и Laravel adapters в два явных context-first
каталога и закрыть D22 сверкой active tenant connection.

**Why:** `P9-design.md` §2–§4.1; D22/D44/D46/D49; `RAG:✅` P9-Q4 делает
bootstrapper order/lifetime correctness-свойством.

**Scope Included:** `Runtime/**`; `Laravel/{Bootstrappers,Commands,Http,Listeners,Resolvers,Scopes}`;
PSR-4 maps для стабильных FQCN; connection-guarded restorer и `scoped` binding;
compatibility/isolation tests; receipt.

**Scope Excluded:** provider/registrar relocation; `Contracts/**`; business contexts; relay scheduler;
автоинициализация tenancy из payload; изменение bootstrapper list/order/lifetime.

**Inputs:** map/baseline P9.1; `research/P9-design.md` §3–§4.1; P8 registrar tree;
D22/D49; `decisions/D100-dynamic-default-connection-and-null-ttl.md`.

**Files:** `packages/tenancy/src/Runtime/**`; `packages/tenancy/src/Laravel/**`;
`packages/tenancy/src/TenancyServiceProvider.php`; `packages/tenancy/composer.json`;
`packages/tenancy/tests/Architecture/**`; `packages/tenancy/tests/Feature/**`;
`findings/P9-receipts.md`; `CHANGELOG.md`

**Required Reads:** 1) `phases/P9/P9.md`; 2) `research/P9-design.md` §0, §3–§4;
3) P9.1 map/baseline; 4) `decisions/D44-laravel-folder-for-registrars.md`;
5) `decisions/D46-context-first-physical-compatible-fqcn.md`; 6) D22; 7) D49;
7a) `decisions/D100-dynamic-default-connection-and-null-ttl.md`;
8) `research/P8-design.md` §2, §5–§9; 9) `packages/tenancy/config/tenancy.php`;
10) current runtime/Laravel source; 11) current tenancy tests.

**Implementation Rules:** Provider и P8 registrar'ы не двигать. Stable seam FQCN из §3
сохранить PSR-4 maps, не aliases. Restorer не делает lookup/init по
payload; делегирует P4 semantic guard и сверяет identity по D49, lifetime `scoped`.
Bootstrapper init/revert прогнать дважды. Enter/leave обязаны менять
и восстанавливать current default connection, а не только connection identity.

**Code Guidance:** Точный owner каждого исходного каталога — §2; проверки
порядка/lifetime — §4/§11; restorer — §4.1. Не переносить RuntimeRegistrar в Runtime.

**Validation:** package lint/analyse/test; `composer test:pg`; baseline/final diff по
bindings с единственной D49-дельтой, bootstrapper order/lifetime,
middleware/commands/listeners; wrong account/workspace/boxed/database red; cloud/boxed green;
unknown account не делает lookup; double init/revert green; one central→tenant→central
cycle exposes the three expected current defaults to a long-lived consumer.

**Deliverables:** Runtime/Laravel tree, connection-guarded restorer, compatibility/isolation tests,
receipt, root CHANGELOG.
