# P9 — Tenancy: bounded contexts вместо смешанной оси

## Phase Context

`RAG:—` Post-P8 baseline будет снят P9.1; design-baseline 2026-09-19 —
159 PHP-файлов и 26 прямых детей `src`. Верхний уровень смешивает
домены, framework adapters и горизонтальные каталоги; все 39 Membership-файлов
спрятаны под `Internal`. `Central` (12) и `Database` (6) прежний эскиз
не размещал.

`RAG:✅` P9-Q1/Q2: крупная модель требует явных bounded contexts,
а domain не должен зависеть от framework/infrastructure. `RAG:✅` P9-Q3
позволяет физическую раскладку без API-break через точечные PSR-4 maps.

> **Контракт фазы.** Потребляет: профили P1, зоны P6, Options P7,
> registrar-модель P8. Производит: 13 context-first каталогов,
> атомарную карту 100% файлов, совместимую FQCN-проекцию и ratchet-гейт.
> Границы: ни DDL, ни public API не меняются; единственная runtime-дельта —
> сверка active connection в `TenantContextRestorer` по D22/D49.

> **Phase Assurance | v1.**
> Impact: public-contract
> Integration Seams: tenancy-public-symbols · composer-psr4 · package-discovery · tenancy-bootstrapper-order · container-bindings · oidc-routes · middleware-aliases · event-listeners · wakeup-integration-allowlist · database-tree
> Live or Irreversible: no
> Audit Intent: direct-close-eligible
> Rationale: физическая DB-per-account изоляция и очереди делают
> даже перенос файлов рискованным; Review всех items — `full`.

## Scope Included

Атомарная post-P8 карта; `Account`, `Authentication`, `Contracts`,
`DomainTrust`, `Identity`, `Impersonation`, `Integration`, `Laravel`, `Membership`,
`PHPStan`, `Provisioning`, `Runtime`, `Workspace`; расформирование
`Membership/Internal`; `Central`→`Membership/Transport`; `Database`→
`Provisioning/Database`; `Oidc`→`Authentication/Oidc`; `Wakeup/Internal`→
`Integration/Wakeup`; PSR-4 compatibility maps; пути PHPStan/CI; package graph allowlist;
structure ratchet; root `CHANGELOG.md`; receipts.

## Scope Excluded

Изменение `Contracts/**`, public/serialized/config FQCN, миграций, DDL, имён
таблиц, connections, bootstrapper order/lifetime, routes, middleware, commands,
listeners, bindings; alias-классы; выделение новых пакетов; переименования
классов P15; multi-account relay control plane до триггера D48.
Исключение из запрета смены bindings — ровно одно: concrete
`TenantContextRestorer` по D49; contract и `scoped` lifetime прежние.
