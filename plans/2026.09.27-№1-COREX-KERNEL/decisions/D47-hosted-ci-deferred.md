# D47 — Hosted CI отложен до восстановления лимитов

**Actor:** owner; recorded by executor/codex/gpt-6-sol/high.
**Evidence:** RAG:— прямое решение владельца в сессии выполнения B02-A:
«про CI пока забей, будем допиливать в конце, как лимиты появятся. делай задачу»;
`research/P02-design.md` §7; GitHub run `36445217833` на `d2e84a1`
отклонён до выполнения шагов из-за billing/spending limit.

## Solution

Hosted CI и устранение его проблем откладываются до заключительной проверки,
после восстановления лимитов GitHub Actions. O-3 не препятствует локальному
исполнению и закрытию items/фаз PLAN3. Это решение отменяет прежнее требование
GREEN hosted CI перед P02.1 и последующими локальными фазами; локальные Validation,
негативные контроли и независимое full review сохраняются полностью.

## Why

Владелец явно выбрал продолжение реализации при недоступном hosted runner.
Локальные проверки дают доказательства только для реально проверенных окружений;
их результат не объявляется доказательством hosted CI или всей CI-матрицы.

## Consequences

Исходные спецификации и GREEN fingerprint дизайна сохраняются; это отдельное
операционное решение о внешнем предусловии. В Completion Notes и итоговом handoff
сохраняется открытый hosted CI residual со ссылкой на D47. До публикации нужно
вернуться к hosted CI и исправить реальные findings после запуска jobs.
Текущий разрешённый workset остаётся P02.1 → P02.2. Push, изменение billing,
публикация и работа над P02.3/P02.4 текущим запросом не разрешаются.
