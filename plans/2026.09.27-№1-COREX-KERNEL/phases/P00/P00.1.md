### P00.1 — Glossary v1 и карты переносов

**Intent:** Зафиксировать окончательные имена и границы ядра CoreX 1.0: пакеты (каталог, composer-имя `axiomasoft/corex[-<name>]`,
namespace-корень, назначение одним предложением, тип), закрытый список модулей ядра, зарезервированные сегменты, FQCN
атрибутов `#[Api]/#[Spi]`, идентификаторы config/publish/команд/env по пакету, и построить машинные карты переносов для P02/P03.

**Why:** D02, D04, D05, D12, D14, D15 задают правила, но не имена; механические фазы P02/P03 исполняются инструментом по карте,
которую исполнитель не должен придумывать. F00 A5.2/A6.3/X1/X4 — коллизии, которые карта обязана устранить.

**Scope Included:** `research/03-glossary.md` (разделы: Naming rules; Packages; Kernel modules; Reserved segments; Attributes;
Identifiers per package; Terms); `artifacts/P00/zone-consumers.tsv` (зона ядра → пакеты-потребители → число импортов →
вердикт keep/move→<пакет>); решение merge `corex/modules` → ядро (замер зависимостей и потребителей); судьба зон ядра;
границы split operations по каталогам `packages/operations/src/*` → engine/tools/webhooks; `artifacts/P00/package-map.tsv`
(old_dir, old_name, new_dir, new_name, new_root, type, phase); `artifacts/P00/namespace-map.tsv` (old_package, old_path,
old_prefix, new_package, new_prefix, phase, note — ключ каталог/файл, не префикс: psr-4 folding, досье §5) — каждый `*.php` под
`packages/*/{src,tests,database}` покрыт ровно одной выбранной строкой (longest-match без src/ fallback); `artifacts/P00/dependency-edges.tsv` — целевой граф и решения разрыва обратных рёбер до split P02;

**Implementation Rules:**
- Критерий пакета (pplx-02): независимый потребитель или шов интеграции; иначе — модуль существующего пакета.
- Критерий зоны ядра «keep»: ≥3 пакета-потребителя **или** зона — механизм надёжности/идентичности платформы (Messaging,
  Audit, Context, Errors, Config, Modules); «move»: один потребитель или тяжёлая внешняя зависимость (brick/money).
- Namespace-корень пакета = PascalCase `<name>` без дефисов; composer-имя kebab-case; module id = composer-имя.
- Каждый `*.php` под `packages/*/{src,tests,database}` покрыт ровно одной строкой namespace-map (longest-match по `old_path`);
  каждый конечный FQCN/целевой путь уникален и принадлежит своему пакету (досье §5.1–4); root symbols/dev roots объявлены отдельно.
- Целевой граф ацикличен, ядро не зависит от расширений; обратные рёбра и provider/snapshot wiring разобраны по §5.7. Развязка — обязательная часть P02 до split; не переносить её в P06.
- Развилка без очевидного лучшего варианта → `open-questions.md` + D# со статусом proposed; иначе — accepted D#.

(исключая `packages/core`), группировка по первым двум сегментам `CoreX\<Zone>`; `check-maps.py` — stdlib, алгоритм досье §5 п.1–7 (режимы
`--doctrine` для P00.2 и `--dependencies` для графа split), коды нарушений и worked examples — `examples.md` §3; exit 1 с перечнем нарушений. Негативный контроль —
