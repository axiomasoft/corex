## Pitfalls

- Не плодить пакеты «на каждый слой» (pplx-02): пакет = независимый потребитель или шов интеграции.
- Имя пакета = назначение (PKG-001), не технология; PascalCase namespace без дефисов.
- `CoreX\Attributes` освобождается только переименованием EAV-пакета — одновременно в одной карте.
- Module id = composer-имя → переименование меняет значения в `mod_*`-таблицах (D01: установок нет, схема сквошится в P08).
- Glossary — норма для P02/P03; каждое имя должно пройти правило §Naming rules glossary (гейт P03).
