### P01.2 — Golden-снимки с нормализатором переименований

**Intent:** Создать Pest-сьют `Golden`, который замораживает публичную поверхность и wire текущего кода (4 слоя:
`php-surface`, `routes`, `events`, `wire`) и сравнивает их с кодом после любого изменения, применяя к baseline только
запланированные переименования из `tests/Golden/rename-map.json` (точные токены по картам P00) — чтобы P02/P03 доказывали
«перенесено, а не изменено».

**Why:** plan §2 «страховочная сетка P01 зелёная перед P02 и после каждого item»; D38; существующий `api/v1`-гейт
сравнивает с baseline, который P02 обязан обновить (имена владельцев), и сам по себе не отличает перенос от поломки
(F6). Карты P00 (666 классов меняют FQCN) — вход нормализатора.

**Scope Included:** `tests/Golden/Support/{GoldenSnapshot,Normalizer,RenameMap}.php`, `tests/Golden/GoldenTestCase.php`,
`tests/Golden/GoldenTest.php`, `tests/Golden/baseline/{php-surface,routes,events,wire}.json`, `tests/Golden/rename-map.json`
(генерация `golden-rename-map.py`), `tests/Golden/REBASELINE.md`; testsuite `Golden` в `phpunit.xml`; composer-скрипт
`golden`; исключение `Golden` из `composer test`; правило anti-weakening для `tests/Golden/baseline/**` (examples §6.3,
третий блок); классы `CoreX\Tests\Golden\…` в `autoload-dev` root (classmap `tests/Golden` или psr-4).

**Scope Excluded:** изменение `api/v1` и `scripts/check-api-contract.php`; `manual`-правила переименований (добавляет P02/P03);
CI-job (P01.4); ownership/PHPStan-гейты (P01.3).

**Inputs:** `plans/2026.09.27-№1-COREX-KERNEL/research/P01-design.md` (§1, §4.2, §5 K5) · `plans/2026.09.27-№1-COREX-KERNEL/research/P01-design-rag.md` · `plans/2026.09.27-№1-COREX-KERNEL/artifacts/P01-design/examples.md` (§3, §6.3) ·

5) `packages/operations/src/OpenApi/Commands/WriteApiSnapshots.php`; 6) `packages/core/src/Events/DomainEvent.php`; 7) `phpunit.xml`

**Implementation Rules:**
- Rename-map — только выход `golden-rename-map.py`; руками не править `generated`/`ambiguous_packages`.
- Правила применяются как точные токены (FQCN-регулярка + точное равенство строки composer-имени); префиксная замена
  запрещена.
- Baseline создаётся один раз (`GOLDEN_UPDATE=1`) вместе с первой строкой `REBASELINE.md`; байтовая воспроизводимость
  двух подряд генераций обязательна (K5).
- Нормализатор исключает только недетерминированные/производные поля; каждое исключение — комментарий «почему».
- Коллектор не трогает БД-состояние других тестов; временные каталоги — `sys_get_temp_dir()` с pid, удаляются.
- Слой не отключается ради зелёного; проблемный класс — в `tests/Golden/Support/skip.php` с причиной (≤5, иначе эскалация).

**Code Guidance:** Скелеты — examples §3.1 (`RenameMap`), §3.2 (`GoldenSnapshot`), §3.3 (`GoldenTest`, `GoldenTestCase`),
§3.4 (`REBASELINE.md`). Провайдеры `GoldenTestCase` — `jq -r '.extra.laravel.providers[]?' packages/*/composer.json` +
`ToolServiceProvider`. `events` дополняется контрактами `MessageContractRegistry`, если он привязан в контейнере.

**Validation:**
- `python3 plans/2026.09.27-№1-COREX-KERNEL/artifacts/P01-design/scripts/golden-rename-map.py --check` → `rename-map OK: 666 class, 16 package, 3 ambiguous, 0 manual`, exit 0.
- `GOLDEN_UPDATE=1 scripts/php84 vendor/bin/pest --testsuite=Golden` → 4 skipped «baseline written»; `sha256sum tests/Golden/baseline/*.json` сохранить;
  повтор генерации → те же хэши.
- `scripts/php84 composer golden` → `Tests: 4 passed`, exit 0.
- Негативный контроль (досье §4.2 п.7): (a) URI маршрута → routes fail; (b) имя публичного метода → php-surface fail;
  (c) namespace класса без `manual`-правила → fail, с правилом → pass; (d) код ошибки → wire fail; после отката → 4 passed.
- `scripts/php84 composer test` → exit 0 (Golden не входит); `bash scripts/anti-weakening-gate.sh` → exit 0; негатив: изменить
  байт в `tests/Golden/baseline/routes.json` без строки `REBASELINE.md` → gate exit 1.
- Independent review: reviewer/effort — из строки `roadmap.md` `execution-sheet/v1`; свежий контекст, reviewer model !=
  executor; вход — item-spec + diff + вывод Validation; строка `review: <provider>/<model> <GREEN|findings:N>`; ≤2 раунда.

**Deliverables:** сьют `Golden` (4 слоя), baseline, rename-map, `REBASELINE.md`, правило anti-weakening; Completion Notes:
размеры слоёв (классов, маршрутов, событий, wire-файлов), хэши baseline, результаты негативов a–d, review.
