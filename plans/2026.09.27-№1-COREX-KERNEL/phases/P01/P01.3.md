### P01.3 — Ratchet-гейты: ownership v2, PHPStan max, dependency-analyser

**Intent:** Поставить три блокирующих с первого дня гейта, чей долг может только сокращаться: ownership v2 (namespace,
таблицы, config, publish-tags, команды, env → пакет по целевой конвенции glossary; ratchet-baseline), PHPStan level max +
strict-rules + bleedingEdge на каждом пакете с baseline и потолком `scripts/quality-ceilings.json`, composer-dependency-analyser
в standalone-установке каждого пакета.

**Why:** D39 (ownership v2; коллизии имён — главный риск P02), D17/D37 (level max, baseline-guard только сужается —
F00 X6), D16/D37 (shadow/unused deps — ошибка). P02 закрывается при `ownership-gate --strict` exit 0 — гейт должен
существовать и иметь измеренный baseline до переименований.

**Scope Included:** `scripts/ownership-gate.php`, `scripts/ownership-map.json` (из glossary), `scripts/ownership-gate-baseline.json`;
`packages/*/phpstan.neon` (20, шаблон examples §5.1), `packages/*/phpstan-baseline.neon`, root `phpstan.neon` (tests/Support,
tests/Golden, scripts) + `phpstan-baseline.neon`; root dev `phpstan/extension-installer`, `phpstan/phpstan-strict-rules`,
`shipmonk/composer-dependency-analyser` (+ `allow-plugins`); `extra.phpstan.includes` в core/modules/tenancy;
`scripts/phpstan-packages.sh`; `scripts/quality-ceilings.json`, `scripts/quality-ceiling-guard.php`;
`packages/*/composer-dependency-analyser.php`, `scripts/dependency-analyser.sh`; объявление shadow-зависимостей;
удаление `scripts/phpstan-contour.php` и `analyse:packages`; anti-weakening: замена строк 71–76 блоками ceilings/ownership
(examples §6.3); composer-скрипты `analyse`, `ownership-gate`, `quality:ceilings`, `deps:analyse`.

**Scope Excluded:** исправление ошибок PHPStan (baseline их фиксирует; чистый max — P09); переименования, устраняющие

**Implementation Rules:**
- Инвентарь ownership — только `src/`, `config/`, `database/migrations/` пакетов (не `tests/`, K6); вывод отсортирован и
  стабилен; baseline создаётся `--write-baseline` один раз в этом item.
- `ownership-map.json` — значения дословно из glossary; расхождение glossary и кода — нарушение в baseline, не правка
  карты под код.
- PHPStan baseline генерируется командой (`--generate-baseline`), не руками; `ignoreErrors` старых конфигов не переносятся.
- Потолки пишет только `quality-ceiling-guard.php --tighten`; рост потолка/ownership baseline в диффе — отказ anti-weakening.
- Analyser: shadow → объявить зависимость; unused → удалить, если нет не-PHP использования; discovery-ложное срабатывание →
  ignore `// discovery: <где>`; архитектурный долг → ignore `// ratchet: <фаза> <причина>`. Глобальные `--ignore-*` запрещены.
- Каждый новый гейт — негативный контроль (досье §4.3 п.5, п.9) с результатом в Completion Notes.

**Code Guidance:** ownership — PHP-скрипт в стиле `scripts/table-ownership-gate.php` (константы `EXIT_OK/EXIT_VIOLATION/EXIT_CONFIG`,
`declare(strict_types=1)`), регулярки examples §4.2, формат вывода §4.3; ceilings guard — examples §6.2 дословно;
`phpstan-packages.sh`, `dependency-analyser.sh` — examples §5.2, §7; PHPStan-шаблон — §5.1.

**Validation:**
- `scripts/php84 php scripts/ownership-gate.php` → `ownership OK: <N> identifiers, <B> baselined`, exit 0; `--strict` → exit 1,
  число нарушений = `B`; негативы (a) дубль config-ключа → exit 1 (O1+O2), (b) удалённая живая строка baseline → exit 1,
  (c) лишняя строка baseline → exit 1 `stale`; после отката → exit 0.
- `scripts/php84 composer analyse` (= `scripts/phpstan-packages.sh`) → каждый конфиг `[OK] No errors`, затем `ceilings OK`, exit 0;
  `ls packages/*/phpstan.neon | wc -l` → `20`; `grep -l "level: max" packages/*/phpstan.neon phpstan.neon | wc -l` → `21`.
- Негатив ceilings: +1 к любому `count:` в baseline → guard exit 1 `phpstan.<p>: … > ceiling …`; откат → OK.
- `scripts/php84 bash scripts/dependency-analyser.sh --all` → exit 0 (20 пакетов); после — `python3 scripts/manifest-check.py` → `manifests OK: 21 roots`.
- `bash -c 'if grep -rn "phpstan-contour\|analyse:packages" scripts tests docs .github composer.json; then exit 1; else test "$?" -eq 1; fi'` → пусто, exit 0; найдена ссылка или ошибка чтения → exit 1.
- `bash scripts/anti-weakening-gate.sh` → exit 0; первое создание ownership-baseline допустимо только при отсутствии файла в base tree; негатив: +1 в `scripts/quality-ceilings.json` → exit 1; новая строка в
  `ownership-gate-baseline.json` → exit 1.
- `scripts/php84 composer test` → exit 0; `scripts/php84 composer golden` → 4 passed (P01.2 не сломан).
- Analyser fail-closed: при ошибке install analyser не запускается; staging key снят в root и tenancy при любом результате.
- Independent review: reviewer/effort — из строки `roadmap.md` `execution-sheet/v1`; свежий контекст, reviewer model !=
  executor; вход — item-spec + diff + вывод Validation; строка `review: <provider>/<model> <GREEN|findings:N>`; ≤2 раунда.
