## Pitfalls

- Все PHP-команды — `scripts/php84`; Python — stdlib, без новых зависимостей (E1: не Pest arch/PHPArkitect).
- Перенос — только инструментом по карте; результат руками не правится, кроме ≤ 20 остатков `verify`, каждый в Completion Notes; дефект → скрипт/карта → новый сухой прогон.
- Golden baseline и `generated` не меняются; растёт только `manual` в `tests/Golden/rename-map.json`.
- Baseline гейта: в P03.1 = `artifacts/P03/module-layout-baseline.current.json`, в P03.2 = `…predicted.json` байт в байт; рост сверх прогноза — только через D#.
- Классы из `public-by-usage.tsv` не переносятся; если гейт/`package-graph-gate` показывает внешнего потребителя у перенесённого класса — это дефект карты, не повод для исключения.
