### P05.3 — Порты вместо фасадов, хелперов и static state

**Intent:** Убрать статический глобальный доступ из runtime-кода пакетов — фасады, глобальные хелперы, статические часы, static mutable state — заменив его зависимостями конструктора с корректным временем жизни, и закрепить это двумя блокирующими гейтами.

**Why:** D09, D70 п.5–9, п.11; RUN-004 и RUN-005 без enforcement. Вне моста — 37 файлов с фасадами, 255 вызовов хелперов (129 `now()`, 80 `app()`/`resolve()`), 12 статических чтений времени, 8 static-свойств. Замена позднего разрешения ранним меняет время жизни: под DB-per-account и резидентным воркером это ошибки класса «запись в базу чужого tenant».

**Scope Included:** Гейт `runtime-globals` G1–G5 с конфигом, baseline и шестью негативными контролями; правила L2 и L3 в `SingletonInjectionGate` с негативными контролями и ремонтом находок; конверсия 16 пакетов по таблице замен; удаление `PubSubManager`, `Closure(): Application` для `ServiceProviderModuleRegistrar`, пустой allowlist; `SystemRoleMutationScope`; baseline только для `packages/tenancy/src/Impersonation/**`; composer-скрипт `runtime-globals-gate`; независимое ревью.

**Scope Excluded:** `packages/tenancy/src/Impersonation/**` (P07, baseline); код внутри `**/Laravel/**`, `*ServiceProvider.php`, `**/Testing/**` (static), `**/PHPStan/**`; существующие параметры `Connection|ConnectionInterface` в scoped и transient-сервисах (вопрос P07, D70 Consequences); новые `CoreX`-порты поверх `Illuminate\Contracts`; замена Eloquent; `products/flex-crm`; подключение гейта к CI (P05.4).

**Implementation Rules:** Поведение не меняется: меняется способ получения зависимости. Время жизни прежде типа: зависимость конструктором допустима, только если живёт не меньше потребителя; иначе потребитель становится `scoped` либо получает resolver или значение. БД — всегда `ConnectionResolverInterface` с вызовом `connection()` в момент операции; item не добавляет ни одного параметра типа `Connection|ConnectionInterface`. Зависимость — интерфейс из D70 п.6, не контейнер и не `Application`. Мутация результата `now()` переписывается на присваивание. Модели, casts и trait-ы Eloquent не читают время и контейнер сами (досье §3.3 п.5). Изменение сигнатуры `#[Api]/#[Spi]` — только по этому правилу и поимённо в Golden delta; изменение `php-api.json` пакета сопровождается записью в его `CHANGELOG.md` (D74 п.9). Baseline не содержит путей вне `packages/tenancy/src/Impersonation/`; allowlist пуст; расширение любого из них запрещено — стоп и эскалация с точным файлом. Тесты, подменявшие время через `Carbon::setTestNow`, переходят на `FrozenClock`, если иначе не проходят. Пакет считается готовым после зелёных тестов этого пакета.

**Code Guidance:** Досье §3.3 шаги 1–11 (порядок пакетов — п.4, правила конверсии — п.5); `examples.md` §6 (L1–L3), §7 (конфиг, правила G1–G5, форматы, поведение baseline, эталон), §8 (таблица замен и before/after для БД, времени, опций, `PubSub`). Playbook §5 — каскад L2, упор в P07-зону.
