## Pitfalls

- `title` из реестра, а не из сообщения: сообщение случая уходит в `detail` (W1).
- Удаление `AcceptNegotiation`/`NegotiatingResponseSerializer` без моста; `rename-completeness` и Golden — по перечню §4.
- Строгость входа не переносится в reader: необъявленные поля проверяет диспетчер для любого конверта.
- `ToolResult::$errorCode` содержит проброшенные коды операций — их не переводить в `tools.*`.
- Extensions CloudEvents — только скаляры: scope — одна каноническая JSON-строка (W6).
- Подпись вебхука считается по сохранённым байтам тела; пере-сериализация ломает подпись.
- Внешний профиль не несёт `dataschema`, `corex*`, `subject`, trace (D92; T6 модели угроз); redacting projector не обязан соответствовать внутренней schema.
- Общий бюджет действует в decide и expired-lease recovery; typed причины сериализуются в SQL через value; ack_unknown не превращается в известный исход.
- Каждый manifest delta сопровождается package CHANGELOG и committed contract-guard; Required Reads ревью — полные разрешимые пути.
- Egress проверяется и на каждой попытке: отзыв разрешения после подписки должен останавливать доставку (W12).
- Golden baseline меняется только reviewed semantic delta; слой routes неизменен.
