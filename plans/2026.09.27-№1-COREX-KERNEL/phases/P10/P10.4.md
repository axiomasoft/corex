### P10.4 — Лейны тестов, покрытие и зелёный hosted CI

**Intent:** Развести тесты по лейнам так, чтобы sqlite-лейн проходил без PostgreSQL, добрать покрытие трёх пакетов до действующих порогов, устранить оставшиеся отказы лейнов Laravel 12 и PHP 8.5 и закрыть фазу полностью зелёным hosted CI.

**Why:** D73, D74 п.5 и п.10. PG-тесты webhooks вне группы `pg` проходили локально только при поднятой базе на порту 5434. Покрытие tools 72.6 %, webhooks 75.9 %, tasks 82.1 % ниже порогов 80, 80, 92. Без зелёного hosted CI фаза не закрывается.

**Scope Included:** PG-методы webhooks в группу `pg` с исполнением в PG-лейне; порт PostgreSQL для PG-теста panels в его джобе; зелёная проверка `test:hermetic` (скрипт определён в P10.1) и mutation-кейс `P10-pg-outside-group`; сверка всех тестов с драйвером `pgsql` на принадлежность группе `pg`; тесты покрытия tools, webhooks, tasks; согласование лейнов измерения покрытия tasks со скриптом и джобом; ремонт оставшихся отказов лейнов Laravel 12 и PHP 8.5; ремонт любого оставшегося красного джоба; закрытие фазы.

**Scope Excluded:** Понижение порогов покрытия и потолков качества; исключение лейнов или тестов из CI; изменения архитектуры P05–P09; причины, принадлежащие P10.1–P10.3 (возвращаются владельцу); workflows `distribution-proof`, `remaining-cohort-proof`.

**Inputs:** `plans/2026.09.27-№1-COREX-KERNEL/research/P10-design.md` (§1, §3.4, §5) · `plans/2026.09.27-№1-COREX-KERNEL/research/P10-design-rag.md` (V3 — `composer update --with` в лейне Laravel 12) · `plans/2026.09.27-№1-COREX-KERNEL/artifacts/P10-design/examples.md` (§2 — `scripts/ci-local.sh`, воспроизведение лейна в чистой копии) · `plans/2026.09.27-№1-COREX-KERNEL/decisions/D73-hosted-ci-acceptance-boundary.md` · `plans/2026.09.27-№1-COREX-KERNEL/decisions/D74-p10-hermetic-base.md` · `plans/2026.09.27-№1-COREX-KERNEL/findings/01-hosted-ci-debt.md` · `plans/2026.09.27-№1-COREX-KERNEL/artifacts/P10-design/facts/repro-root-tests.txt` · результаты P10.1–P10.3 (`plans/2026.09.27-№1-COREX-KERNEL/artifacts/P10.{1,2,3}-execution/completion.md`, появляются после их исполнения)

**Implementation Rules:** Тест, открывающий соединение с PostgreSQL, состоит в группе `pg`; условный `markTestSkipped` по имени базы группу не заменяет. Sqlite-лейн не обращается к PostgreSQL ни при каких значениях окружения. Пороги покрытия, потолки PHPStan, baseline и allowlist не ослабляются; покрытие добирается тестами поведения, а не тестами ради строк. Несовместимость с Laravel 12 чинится в коде (D03): лейн не исключается. Ни один тест не удаляется и не помечается пропущенным ради зелёного запуска; пропуск допустим только по отсутствию расширения с явной причиной. Причина, принадлежащая P10.1–P10.3, возвращается владельцу, а не обходится. Исправление, меняющее поведение кода в `packages/*/src` (не тесты и не CI-рецепт), до закрытия item проходит независимое ревью по runbook `full` из `session-routing.md` (D73 п.7, D76). Джоб со статусом `skipped` по условию события (`Mutation registry` исполняется только на `pull_request`) отказом не считается; реестр mutation-кейсов проверяется локально. Фаза не закрывается при любом красном джобе workflow `CI`.

**Code Guidance:** Досье §3.4 шаги 1–8. Приём `PGSQL_PORT=1` уже используется mutation-кейсом `P1.14-pg-lane-split`. Непокрытые ветви определяются отчётом `pest --coverage` пакета; приоритет — ветви отказа и граничные условия.
