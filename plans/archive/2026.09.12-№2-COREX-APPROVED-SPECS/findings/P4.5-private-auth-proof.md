D14 authorized only a read-only, disposable fixture. The canonical private
source was inspected at immutable commit
`8c83864f02017134b325224c6c8be590a3971485` (tree
`08ef009a34727006d4e84ba8c24e592824363913`) in
`https://github.com/axiomasoft/azguard.git`. Its package is
`axioma-studio/azguard-core`; the canonical source composer and LICENSE
SHA-256 values were respectively
`e6bb975ea31b5fc8df6084d200e367a5f03c8173e96366343573d91765cff2ca`
and `6d3c95134ac602c836fde922039d648584f4af06e061cd12f6594aa6e9dda20a`.

temporary ZIP and makes a local Composer metadata fixture. It neither stores
credentials nor copies private source into this repository. The transformation
has local candidate version `0.2.0-p4.5`, a canonical source reference, and
the following receipts:

  `160b62c08fbb6514b7823d923a4ad0f9e100aa984d1c40f56dd7605d30d52a98`;
- private ZIP SHA-256:
  `b487ce8b703359cb57a77083c1dd44685d1cf7856053b9c66a76cf4cd07f1574`;

  `1f4d4d63b4285b025804618b1cb2e421fc04e6c03f600d77dc68a37e063fcb07`;
- auth-as-dependency cold-lock SHA-256:
  `fddba0846b8bda14ebc73765276d7d8082a71f79fced346eedd5a10994b72c30`.

Each role performed a fresh update, deleted vendor/home/cache, then installed
again from its saved lock. Both installed an ordinary vendor tree, not a path
link. The focused private proof test passed (one test, four assertions).
`packages/auth/composer.json` has no path repository, sibling checkout or
unconfirmed `azguard-private` remote; consumers must configure their own
canonical private channel because Composer repositories are non-transitive.

The ignored local `packages/auth/composer.lock` remains a historic developer
lock and cannot be a published private-channel proof: its previous path source
is deliberately not retained in released metadata. Existing auth package
source suites were attempted after PG16 preflight but their already-installed
Testbench bootstrap fails before test execution with `Unknown named parameter
$annotation`; this pre-existing runner mismatch is distinct from the two
passing sealed private consumer roles and is not represented as a passing
suite.
