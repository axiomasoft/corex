# P4.3 — local durable pair-store proof

**Result:** local GREEN for the D8 unregistered-library scope only. The
implementation is `Membership/Internal/Persistence`, with a disposable
PostgreSQL fixture. It preserves the existing public tenancy interfaces,
contracts, service-provider registrations, dependencies, and production DDL.

## Local invariants exercised

- R/G/E/F/AF use canonical exact decimal strings; values around `2^53`, signed
  64-bit bounds, unsigned64 max, and rejected invalid forms are covered before
  SQL binding.
- A repeated operation UUID keeps F stable; a newer F leaves a valid committed
  AF intact. A stale operation UUID cannot later commit.
- A barrier is durable and idempotent: repeated crash/replay of the same barrier
  increments E once, clears AF, and leaves the pair denied.
- R/G regression is rejected. Restore is denied when its independent witness is
  missing or behind; a current witness advances only to its high-water marks and
  still closes admission/clears AF for fresh authentication.
- The PG fixture proves the declared `numeric(20,0)` round trip and the database
  CAS transition. It is not an effective central ledger, witness service,
  production mapping, or recovery procedure.

## Scoped concurrency/security review

A second pass checked the concrete shared-state risk: counter conversions happen
before SQL; pair mutation locks the exact `(account_id, identity_id)` row; each
write that could publish uses the current operation UUID; newer F cannot erase a
previously committed AF by itself; deny removes AF; and restore cannot reset a
counter or re-open authorization. No public or runtime surface was introduced.
