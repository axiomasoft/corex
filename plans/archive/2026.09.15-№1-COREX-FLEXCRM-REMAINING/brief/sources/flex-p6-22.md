### P6.22 — Agentic surface app: MCP v1 + тулзы модулей + eval-сет → GREEN

**Intent:** Реализовать agentic-поверхность приложения: MCP v1 сервер FlexCRM (`laravel/mcp`), регистрация тулз всех модулей (24 канонных CRM-тулзы B-13 §3.8 + `att.*` 13 + тулзы соц/календаря/маркетинга/студии), агенты поверх `corex/ai`, permission-гейты принципала `agent`, eval-сет ключевых сценариев — до GREEN.
**Why:** AI-native дифференциатор продукта: агентский доступ к CRM через MCP — то, чего нет у Б24/amoCRM; партнёрские интеграции идут через ту же поверхность. RAG:✅ B-32 §7 (карты тулзов) + B-13 §3.8 (24 канонных тулзы) + `laravel/mcp` пин v0.8.2 2026-07-13.
**Scope Included:** MCP v1 сервер в app-репе; регистрация ToolProvider'ов модулей; аутентификация (Sanctum PAT — v1); permission-гейты на мутирующих тулзах; eval-сет (`architect/eval-design`) на ключевые сценарии; exec до GREEN. **Дополнено P8.6 (C-99b §4.8):** REST-проекция тех же Action'ов модулей (`/api/v1`, B-37 §5.5–§5.6) — единственный источник истины операции есть Action, MCP-тулза и REST-эндпоинт — две независимые проекции, реестры не дублируются (N1); носитель REST-слоя `/api/v1` — `corex/api`, майлстоуна которому нет (**M6/Q88, открытый вопрос владельца** — handoff FLEX-2, `/task:plan-design FLEX-2 P6`); до его решения REST-проекция этим item'ом НЕ строится, MCP-часть исполняется независимо.
**Scope Excluded:** пакет `corex/ai` (P6.15 — потребляется); OAuth 2.1 AS для MCP (v1.1); ControLLM gateway; MCP спутников (их репы).
**Inputs:** `corex/ai` (P6.15) · §7-карты тулзов модулей (B-27…B-32, B-36) · B-13 §3.8 · vault `API_Endpoints (FlexCRM).md` (84 тулзы — реестр после P7.5) · AGENTOOLS-спека (нормативная ссылка, Q28 Deferred).

Норматив N1–N12 обязателен для КАЖДОЙ тулзы (проверяется `module.lint` из P6.15). Модель-ID LLM — из конфига (актуальные Claude-модели, версии через RAG), не хардкод.
**Code Guidance:** ДЕЛЕГИРОВАНИЕ + agent-дисциплина. Тулзы — тонкие и детерминированные: одна тулза = одна операция + явный контракт вход/выход; мутирующая тулза БЕЗ permission-гейта = блокер. Обязательные тесты: агент без права не выполняет мутацию (негативный тест на каждую мутирующую группу); тулза не возвращает данные чужого тенанта; eval-сет ключевых сценариев (создать сделку, найти по описанию, отчитаться по табелю) зелёный и запускается в CI (регресс). Запрещено: побочные эффекты без гейта; «умные» тулзы, скрывающие несколько операций; агенты без eval-покрытия; хардкод устаревших model-id.
**Validation:** `task:plan-audit` делегата = GREEN; MCP-сервер стартует, тулзы вызываются в интеграционном тесте; негативные permission-тесты зелёные; eval-сет зелёный в CI; `module.lint` (N1–N12) по всем зарегистрированным тулзам зелёный.
**Deliverables:** MCP v1 + агенты FlexCRM + eval-сет в CI + план закрыт + Status Board.
