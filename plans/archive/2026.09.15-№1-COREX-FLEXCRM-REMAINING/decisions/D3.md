## Decision

Детализировать P1 четырьмя пунктами: P1.1 source reconciliation → P1.2 lossless atomic AC map
и P1.3 semantic baseline/evidence qualification → P1.4 lock/conflicts/downstream gaps.
52 R, 365 parent criteria, 100 source IDs, A01–A09, E1–E5 и полный G-*/34 DI/13 AP набор сохраняются.
Original parent text/hash/R mapping инертен; corrected classified atoms требуют concrete correction.
Working claims без binding остаются proposal с owner/resume, источник не переписывается.

P1.1 выполняется implementation/medium (gpt-5.6-terra); P1.2/P1.3/P1.4 — frontier/high
(gpt-5.6-sol) из-за mixed ownership, semantic equivalents и lossless reconciliation.
P1.2/P1.3 recommended shared batch допускает ready subsets. Child agents и phase audit не назначаются.
Локальный scripts/validate-p1.py проверяет структуру, completeness и byte pins; scripts/task-check.py находит configured Task runtime и вызывает shared structural gates без machine-specific execution inputs; содержательное
покрытие всех original clauses и receipt boundaries обязательно по item Validation.

## Alternatives

- Один research item: смешивает source/evidence producers и seal, затрудняет проверку утрат и scope conflicts.
- 52 пункта/17 blueprint проходов: повторяют source reads и разводят mixed criteria; bounded четыре carriers сохраняют общий context.
- Превратить legacy B10/B11/B12/17-package перечни в CoreX API/DDL: противоречит D2 и docs doctrine;
  parent сохраняется, механизм/policy/ops/excluded outcomes разделяются, contract choices принадлежат P2.
- Блокировать весь freeze до DI/AP/cloud acceptance: неверно связывает pure utility design с live deployment;
  точные missing receipts остаются открытыми и обязательными для owning P10/P11.

## Source observations

Проверено: 100 оригинальных source hashes/snapshot/committed blob carriers совпадают;
provenance — 66 untracked, 30 committed, 4 modified. 365 unique parents и 52 R, source links доступны.
Проверка не означает source-owner acceptance working claims или runtime test run.
Старый handoff упоминает Q1–Q6, но ни D1/D2, ни generated open-questions не содержат этих записей.
Нельзя выдумывать шесть вопросов; ссылка снимается. Будущая P1.4 материализует реально доказанные
conflicts/owners/resume и при необходимом consequential выборе использует existing decision carrier.

**Consequences:** Меняются только P1 specifications, P1 dispatch rows, этот D-record и owned plan views/handoff.
P2–P11 остаются skeleton; A01–A09 и scope D2 не пересматриваются. Нет grants для API/DDL/major/release,
private/live или foreign write. P1 GREEN — completeness of freeze, не production acceptance.
Design завершится recommendation P1.1 с cold-start-root: design-root-terminal; исполнитель этой сессией не запускается.
