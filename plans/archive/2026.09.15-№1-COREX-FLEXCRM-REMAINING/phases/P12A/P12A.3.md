**Intent:** Перевести результат восьми закрытых item P12 и коррекций P12A.1–P12A.2 из рабочего дерева в репозиторий единственным scoped-коммитом с русским Conventional-сообщением, так чтобы фаза P12 существовала как ревизия, а не как несохранённое состояние машины.

**Why:** Дефект R1 `findings/P12-post-close-audit.md`. HEAD — `904ac87 fix(packages): починить P0 границ пакетов (P12.1)`; всё, что произвели P12.2–P12.9, лежит как 22 untracked, 76 modified и 63 rename-записи, включая сами носители результата: `scripts/package-graph-gate.php`, `scripts/package-graph-gate.json`, `tests/Arch/PackageGraphTest.php`, `packages/search/src/SearchManager.php`, `packages/attributes/src/Data/`, `packages/core/src/Contracts/DataScopeAuthorizer.php`, триаду `docs/audit-2026-09-17*.md` и саму проекцию `phases/P12/P12.closed.md`. §1 протокола: репозиторные файлы — источник истины; §7: закрытие идёт одним scoped-коммитом с реализацией и затронутым bookkeeping. Ни один terminal-event P12.2–P12.9 не несёт commit-ссылки. Одна `git clean -fd` или свежий clone уничтожают восемь item.

**Scope Included:** Единственный коммит, включающий: продуктовые изменения P12.2–P12.9 (`packages/**`, `scripts/package-graph-gate.*`, `tests/Arch/PackageGraphTest.php`, корневой `composer.json`, `CHANGELOG.md`, `docs/dev-doctrine.md`, триаду `docs/audit-2026-09-17*.md`), стилевые правки P12A.2, обновлённый binding P12A.1, и bookkeeping плана (`phases/P12/**`, `phases/P12A/**`, `findings/**`, `decisions/D42-p12-post-audit.md`, `journal.jsonl`, генерируемые проекции). Сохранение rename-записей git для `packages/import-export/` → `packages/transfer/` и `packages/intl-search/` → `packages/search-intl/`, чтобы история файлов пережила коммит. Решение по `artifacts/P12-package-graph/report.json`: либо коммит как объявленного в `P12.3.md:13` Files-артефакта, либо явное игнорирование с записью причины — одно из двух, выбранное и обоснованное в receipt.

**Scope Excluded:** Любая правка продуктового кода в этом item — коммитится ровно то, что произвели P12 и P12A.1–P12A.2; `git commit --amend`, `rebase`, `reset`, `push` и любое переписывание существующей истории, включая `904ac87`; второй коммит без реального ownership/session boundary или digest-input collision; `git clean`, `git checkout --` и любая команда, способная потерять незакоммиченное; изменение `.gitignore` ради исключения продуктового файла из коммита; каталоги миграций.

**Inputs:** `findings/P12-post-close-audit.md` раздел R1 как полный перечень незакоммиченного и точные счётчики `git status --porcelain`. `findings/P12A-correction-receipts.md` разделы P12A.1 и P12A.2 как подтверждение, что дерево на момент коммита зелёное по design-гейту и по `lint:check`. `phases/P12/P12.closed.md` и `findings/P12-rebaseline-receipts.md` как перечень того, что фаза P12 обязалась произвести — он же критерий полноты коммита.

**Files:** Изменений содержимого файлов этот item не вносит; он фиксирует существующее состояние дерева в ревизии. Receipt item'а — `findings/P12A-correction-receipts.md` (append). Собственный append-only journal и генерируемые state/status/проекции.

**Required Reads:** `plan.md`; `findings/P12-post-close-audit.md`; `decisions/D41-package-boundary-rebaseline.md`; `decisions/D42-p12-post-audit.md`; `decisions/D6.md`; `findings/P12A-correction-receipts.md`; `phases/P12/P12.closed.md`; `findings/P12-rebaseline-receipts.md`; `.gitignore`. `.gitignore` читается, чтобы отличить намеренно неотслеживаемые каталоги (`delivery/`, `plans/**/.plan-cache/`) от продуктовых файлов, которые обязаны попасть в коммит.

**Implementation Rules:** Перед мутацией `python3 plans/2026.09.15-№1-COREX-FLEXCRM-REMAINING/scripts/task-check.py --check design` даёт exit 0. D6 — нейтральные внешние запросы; они этому item не нужны. Полная цепочка гейтов обязана быть зелёной **до** коммита, а не после: коммитить красное дерево запрещено. Сообщение — русский Conventional Commit по действующему правилу репозитория, с перечислением закрываемых item. Rename фиксируется как rename: перед коммитом проверить `git status --porcelain` на наличие статусов `R`/`RM` для обоих переименованных пакетов и `git log --follow` после коммита на одном перенесённом файле каждого пакета. Untracked-файлы добавляются поимённо или каталогами из Scope Included; `git add -A` без предварительной сверки `git status --porcelain` с этим перечнем запрещён — именно необнаруженная разница и породила R1. Ни один файл не исключается из коммита молча: всё, что остаётся неотслеживаемым после коммита, перечисляется в receipt с причиной. Каталоги миграций не трогаются; их пустой дифф проверяется отдельно. Предшественники: item исполняется только после закрытых P12A.1 и P12A.2.

**Code Guidance:** Изменения кода нет. Форма сообщения — по образцу существующих коммитов ветки: `fix(packages): починить P0 границ пакетов (P12.1)`, `docs(plan): закрыть P7.9 и перенести qualification receipts в artifacts`. Тип выбирается по преобладающему содержанию change-set'а; область — затронутый слой; тело перечисляет закрываемые item и называет, что коммит фиксирует результат уже закрытых P12.2–P12.9, а не вводит новый.

Receipt с фактическим выводом всей цепочки гейтов до коммита, `git show --stat HEAD`, `git status --porcelain` после коммита, доказательством сохранности истории для обоих переименованных пакетов и явным перечнем файлов, оставшихся неотслеживаемыми, с причиной по каждому.
