# Maintained Laravel Rector subset

These are CoreX development tools, derived from the MIT-licensed
`driftingly/rector-laravel` 2.6.2 commit
`c0f9a2ff7365cec45d4dc64223608e7cec74604a`. They are not installed or exported by
CoreX consumer packages. The upstream MIT copyright and license are retained in
`Laravel/LICENSE`.

The subset owns exactly 36 rules (25 quality, four collection and seven type
declaration rules), their 46-file production dependency closure, and the default
two context visitors. The three local set configs preserve upstream Composer
version constraints, including the different relation-generic formats.

The old `getRuleDefinition()` documentation metadata and
`DocumentedRuleInterface` are removed. Native Rector 2 transformations remain;
there is no Composer `replace`, abandonment waiver or hidden installable root.
Original source, configs, official fixture support and 79 upstream stubs are
stored as non-executable data in `upstream.json`, with their exact official Git
blob SHA and SHA-256 hashes. Tests reify fixtures into an owned temporary
directory and run their original 36 test classes in an isolated subprocess.
The stub class loader exists only in that subprocess, never in the root test
process or analysis configuration.

`Import/DocumentationVisitor.php` performs the bounded AST namespace and metadata
transformation. `native-adjustments.json` records the byte edits from that
deterministic baseline to the reviewed native implementation, with input and
output hashes. These include project formatting/strict types, native `Node`
guards instead of parameter annotations that violate the Rector interface,
PHPStan's public Type/PhpDoc APIs instead of deprecated type-class inspection,
and the two explicit project behavior policies below. No static-analysis
suppression or fake framework definition is used in owned production source.

Both `DispatchToHelperFunctionsRector` and `ServerVariableToRequestFacadeRector`
accept `PRESERVE_PATHS` (`preserve_paths`): a list of existing absolute bounded
file/directory paths. The default is an empty list, preserving official upstream
behavior. CoreX config registers production source directories for dispatch,
preserving `Job::dispatch()` and its `PendingDispatch`/uniqueness behavior, and
the exact request-free module CLI argv reader for the server rule. Adjacent
paths keep transforming normally. Malformed/unbounded paths are rejected.

Validate with PHP 8.4:

```bash
scripts/php84 php scripts/quality/rector/import.php --check
scripts/php84 php tests/Tooling/Rector/run.php
scripts/php84 vendor/bin/pest tests/Arch/RectorLaravelSubsetTest.php
scripts/php84 vendor/bin/pint --test scripts/quality/rector tests/Tooling/Rector tests/Arch/RectorLaravelSubsetTest.php
scripts/php84 vendor/bin/phpstan analyse -c phpstan.neon scripts/quality/rector --no-progress
```

`import.php --check` validates all original hashes, resolves the production
dependency closure and compares regenerated bytes. Changed inputs, missing
classes, modified generated bytes and unexpected source files fail. Without
`--check`, it writes regenerated outputs. `--baseline --destination=<directory>`
exports the unadjusted AST baseline for reviewing/updating the recorded edits;
use a temporary directory outside analysis roots.

On upstream updates, update the pinned commit, selection, original hashes and
official fixtures together; inspect the semantic delta and regenerate the byte
adjustments. Run all 173 original fixtures, policy controls, reproduction and
normal root Rector/Pint/PHPStan/audit gates. Return to an upstream stable extension
once it removes the abandoned dependency and passes these equivalence checks.
